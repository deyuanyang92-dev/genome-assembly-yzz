## 工作范围和前置条件

原始DNA reads必须先经过既有调查/组装/QC，形成版本冻结的目标核基因组FASTA，才能开展基于基因组的结构注释。只有RNA可以重建转录组，不能凭空获得全基因组坐标。HiFi genomic DNA不等于Iso-Seq HiFi cDNA；Illumina WGS不等于Illumina RNA-seq；Hi-C不能替代RNA表达证据。

注释分为：重复序列与TE；蛋白编码基因的gene/transcript/exon/CDS/UTR；ncRNA；功能与同源关系。单个基因预测器不覆盖全部任务。两hap/多倍体的注释分开保存，不能删除真实等位/同源拷贝来降低BUSCO D。只注释primary时明确覆盖范围。细胞器走适用的遗传密码和独立工具分支，不能直接套核基因模型。

### BRAKER4的版本相关要点

官方README提供samples.csv/config.ini入口；迁移教程涵盖旧braker.pl到新配置的转换。在线可见默认分支名为cleanup/filter-stop-codons-leftovers，不能假定存在main。核查了README的模式/输入、config.ini.example、迁移说明，以及Snakefile中IsoSeq/dual的include与后处理相关段落，未审计全部规则实现。

PacBio IsoSeq及dual均要求蛋白证据；dual包含短RNA和IsoSeq两个GeneMark-ETP分支。README列可选自动masking、UTR补充、ncRNA和QC；具体启用项要核对固定版本。config.ini.example中的run_ncrna默认0；不能把执行成功解释成已注释全部ncRNA。内置best_by_compleasm可优化BUSCO保留，因此BUSCO不是独立盲测证据。

本轮未发现该文档对ONT拥有与PacBio IsoSeq相同的原生模式承诺；ONT优先走已明确支持它的IsoQuant/EviAnn证据分支。不能仅把ONT文件填进isoseq_fastq就宣布支持。GeneMark依赖的使用许可及数据库下载条件需单独记录，不自动声称容器内所有组件都无约束。

[迁移手册](https://github.com/Gaius-Augustus/BRAKER4/blob/cleanup/filter-stop-codons-leftovers/MIGRATING_FROM_BRAKER3.md)、[配置示例](https://github.com/Gaius-Augustus/BRAKER4/blob/cleanup/filter-stop-codons-leftovers/config.ini.example)、[Snakefile](https://github.com/Gaius-Augustus/BRAKER4/blob/cleanup/filter-stop-codons-leftovers/Snakefile)。

## RNA、重复、整合与质控配套

| 层 | 候选 | 需要保存的关键产物/注意点 |
|---|---|---|
| 重复/TE | RepeatModeler2+RepeatMasker，Earl Grey；植物等适用场景评估EDTA | 自建库、分类库/分区版本、TE GFF和softmasked FASTA；masking不删除基因组坐标；基因重叠不能一概删 |
| 二代RNA | fastp/FastQC/MultiQC，STAR或HISAT2，StringTie | 按文库保留BAM、剪接junction、组织信息；已比对文件必须匹配FASTA SHA |
| 三代RNA | IsoSeq工具链或ONT预处理，minimap2/pbmm2，IsoQuant，SQANTI3 | 模型、原始分子支持、剪接/末端/内部引物和RT-switch等风险；见41 |
| 蛋白同源 | 合适OrthoDB clade、近缘高质量蛋白；miniprot/ProtHint | 来源、物种距离、冗余过滤和序列hash；不要把多个源重复记录成独立支持 |
| 整合 | TSEBRA、gfftk consensus、Mikado；固定EVM对照 | 输入格式和证据语义不相同，需适配；见42 |
| UTR/异构体 | StringTie证据、必要时PASA更新 | 保留RNA支持和前后变化，不能无RNA补出已验证UTR |
| ncRNA | tRNAscan-SE、Infernal/Rfam、适用rRNA工具；有条件的lncRNA候选 | 编码潜能、重复和证据单独标注；普通polyA RNA不足以证明miRNA/所有ncRNA完备 |
| 功能 | eggNOG-mapper、InterProScan、DIAMOND对Swiss-Prot等 | GO/结构域/同源/通路证据逐来源保存；预测功能不冒充实验验证 |
| 质量/格式 | BUSCO、OMArk、gffread、AGAT/GFFtk、浏览器抽查 | 蛋白集与基因组BUSCO分开；检查相位、翻译、融合/碎裂、TE伪基因、缺失及污染 |

[Earl Grey](https://github.com/TobyBaril/EarlGrey)当前文档强调软件与Dfam版本配套；[EDTA](https://github.com/oushujun/EDTA)是TE注释器，不能覆盖基因注释。[OMArk](https://github.com/DessimozLab/OMArk)评价蛋白库完整性、同源一致性和污染；受数据库类群覆盖影响。[InterProScan v5](https://interproscan-docs.readthedocs.io/en/v5/HowToRun.html)、[eggNOG-mapper](https://github.com/eggnogdb/eggnog-mapper)提供互补功能证据，不能借功能命中率替代结构准确性。本轮没有审完上述所有工具的全部参数或下载数据库。

## 已有本地环节动物用法：Galeolaria

固定提交01c252196c6a8ba7c8fd93376ded2bb266eb3e7e，来源[moniquevdor/GaleolariaReferenceGenome](https://github.com/moniquevdor/GaleolariaReferenceGenome)。本轮补读AnnotationPipeline的repeat、二代比对、IsoSeq处理、GeneMarkS-T、TSEBRA和部分功能注释脚本。

实际链条是RepeatModeler/RepeatMasker→二代STAR→IsoSeq lima/refine/cluster、pbmm2/collapse→RNA单独BRAKER和蛋白单独BRAKER→转录本ORF转基因组坐标→TSEBRA加long-read配置→GFF规范化/蛋白→InterProScan/eggNOG。容器叫braker3并不表示每个命令都运行RNA+蛋白联合BRAKER3；必须按实参判断模式。

静态注意点：

- repeat脚本使用--xsmall，含义是softmask，并非注释文字所谓“删去重复”；ProtExcluder处理库也要核实生物学影响。
- 旧IsoSeq cluster已非当前官方首选；本脚本期待polished.hq.bam，不能把cluster2产物套同名后续。
- StringTie2.1.5处理三代RNA的一行未见-L；按当前官方长RNA说明需要核查此模式，不能无条件复用。此处也是与isoseq collapse并列的产物，不声称已证明影响最终注释。
- STAR索引FASTA名为Rearranged，而其他预测使用Final_masked；无法仅靠名字证明相同版本，需要hash、序列ID和长度/坐标核对。
- 占位路径、module、容器绑定/版本与species模型复用状态都需要替换/审查；未见整个链统一的失败/缓存契约，不能当零配置成品。
- TSEBRA长读段模型参数来自指定旧教程/配置，不能直接套最新版本。功能脚本也应固定数据库并检查真实输出。

这些是静态发现，未跑样本验证，不称已确认生物学错误。源码hash与阅读范围见sources/annotation_review.json。下一步是固定候选版本、准备官方小例和目标类群样本，按42做公平对照；这一步尚未完成。
