# 全基因组组装基础与质量判断

更新：2026-11-01。目的：理解工具输出背后的生物学问题，形成能用于流程选择和异常诊断的判断方法。适用于本项目关注的真核核基因组；细菌、宏基因组、多倍体等需调整模型。本页“处理建议”是结合原始研究、官方说明与数据依赖条件作出的项目建议，不是任一软件自动保证。

## 1. 先知道我们要重建什么

- **基因组大小**要说明一套染色体的长度，还是细胞内所有拷贝总长度；二倍体的两个 hap 通常各接近一套长度，真实缺失、性染色体和重复差异会造成不等长。
- **contig** 是连续组装序列；**scaffold** 将若干 contig 排序定向，常以 N 表示未知间隔。挂载改善长程组织，不能把未知间隔变成已测定碱基。
- **primary/alternate** 不是两个对称、完整的亲本基因组；**hap1/hap2** 也要看生成模式。只有 HiFi 时可有局部分型或 dual assembly，但不能默认全染色体都来自同一亲本。
- **分型**回答同一同源染色体的等位序列是否被正确分开；**挂载**回答 contig 如何归组、排序和定向，两件事需要分别评价。hifiasm 官方说明 Hi-C 模式可以在染色体内分型，但不同染色体的父母来源会混合；常规Hi-C分型输出还需按目标另做scaffolding；较新版本的可选self-scaffolding应单独记录，见30。[hifiasm 官方 Hi-C 文档](https://github.com/chhylp123/hifiasm/blob/master/docs/source/hic-assembly.rst)

## 2. “准确”和“正确”必须拆成多个维度

| 要问的问题 | 应查看的证据 | 单独不能说明什么 |
|---|---|---|
| 碱基是否准确 | 同个体高准确 reads 的 k-mer QV、局部 reads 支持、错误候选 | QV 高不能证明跨染色体连接正确 |
| 是否漏序列 | 可靠 k-mer 完整度、基因完整度、预期长度、覆盖缺口 | BUSCO 高不表示着丝粒/端粒/重复区完整 |
| 拷贝数是否正确 | spectra-cn、深度、self-alignment、组装图、倍性 | 组装更长不一定更完整，也可能冗余 |
| 染色体结构是否正确 | Hi-C 图、长 reads 局部支持、光学图谱/遗传图谱/Strand-seq、核型 | N50 大或 scaffold 数等于染色体数都不足以证明正确 |
| 两 hap 是否正确分离 | 适用的亲本 hap-mer、相位块/切换错误、其他分型证据 | 没有标记真值时，不能仅凭两份 FASTA 宣称完整亲本分型 |
| 是否混入非目标序列 | 分类命中、GC–深度、同个体 reads 支持、基因/邻接证据 | GC 离群不等于污染，单个外源命中也不能直接删除 |
| 有多连续 | contig/scaffold N50、NG50、L50、gap/N、未挂载比例 | 连续性描述不等于正确性；NG50 的预期长度必须有依据 |

**项目推理示例：**把两个无关染色体 contig 错接起来，N50 可增大，原有 BUSCO 也可以完全不变。如果只是重排保留全部序列，k-mer 内容指标也可能变化很小。这三项都改善或保持，结构仍可能错。

QV 的定义是 `-10 log10(估计每碱基错误率)`；Q40 对应模型估计约万分之一，Q50 约十万分之一。Merqury 由 k-mer 推导此估计，结果受评价 reads 覆盖和偏倚影响。使用构建 assembly 的同一批 reads 时，评价并非完全独立；应披露。低覆盖可能低估 QV，错误 k-mer 也可能影响结果。未检出错误或显示无穷大不等于证明绝对无错。分 hap 与两 hap 合集完整度要分别解释，不能用单 hap 丢失另一 hap 的特异 k-mer 直接判为缺失。[Merqury 原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7488777/)

BUSCO 衡量指定谱系预期保守基因的恢复情况。重复 BUSCO 可能来自生物学复制或组装冗余；缺失也可能与谱系/预测有关。必须保存 C/S/D/F/M、谱系库版本及 assembly 角色。把两个完整 hap 合在一起后发现很多重复，不能直接作为 purge 理由。[BUSCO 官方解释](https://busco.ezlab.org/busco_userguide)

## 3. 只有 HiFi：可以怎么做、如何判好坏

**建议路径：**样本登记和 HiFi QC → 基因组调查 → HiFi 组装并保留 GFA/原始输出 → 多维评价 → 有证据才 purge/清理/修正 → 发布与证据匹配的 contig 产品。

1. 确认 reads 是否来自单个个体，质量、有效总量和读长分布；混多个二倍体会增加单倍型复杂度，不能直接沿用单个二倍体解释。
2. 看 k-mer 直方图和模型拟合，结合流式/核型等信息判断规模、杂合和倍性。GenomeScope 2.0/Smudgeplot 原论文建立在低错误短读长数据上；用于 HiFi 时需核对当前实现、预处理和拟合适用性，不能照搬覆盖阈值或把异常峰直接解释成多倍体。[原始论文](https://www.nature.com/articles/s41467-020-14998-3)
3. 保存 primary/alternate 或选定模式的输出，不机械要求两者等长，也不因总长度接近2G立即去一半。结合深度、等位比对和 k-mer 拷贝证据区分未折叠 haplotigs、真实复制与重复塌缩。
4. 用同个体 HiFi 回贴检查局部覆盖、错配、分裂比对和支持断点的独立分子。重复区多重比对、等位差异和结构杂合会产生类似信号，要联合解释。Inspector 可补充查找结构/小尺度错误，但其报告仍有检测范围和模型限制。[Inspector 原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8590762/)
5. 用适用 reads 进行 k-mer 评价、选对 BUSCO 谱系、检查污染；分 assembly、分阶段对照。另一个组装器的差异可提供候选问题，不能多数表决当真值。

**能力边界：**没有 Hi-C 仍能获得很连续、甚至个别完整染色体的 contig；但无法仅凭 HiFi 例行保证所有 contig 的染色体归属和远距离方向，更不能把零 N 等同 T2T。已知端粒 motif 两端出现只是线索，还需排除误拼、内部端粒重复和未解决重复区。未知染色体上的 contig 可以保留未定位，比强接更可解释。

### 用户指定的数据量验收：最低50×

用户要求后续每次报告必须回答“HiFi数据量是否足够”，最低按**有效HiFi碱基量D/单套核基因组大小G ≥50×**验收。这是本项目要求，区别于外部文献的推荐起点；二倍体50×总覆盖对应每hap平均约25×，不是每hap50×。

先用k-mer调查估计G，再结合primary长度、拷贝谱、污染和回贴结果复核。primary长度可能受冗余或塌缩影响，不能作为唯一分母，也不能把primary与alternate简单相加。保留原始数据量、有效量及过滤依据，避免重复统计相同reads；已确认污染及非目标细胞器reads不用于抬高目标核数据量。未能可靠区分时披露限制，不把名义总量冒充已核实的核覆盖。

每次报告列出：G及估计依据/范围、有效D、D/G、最低50×、达标状态、距50×的有效数据缺口`max(0,50G-D)`。若G在[Gmin,Gmax]内，则覆盖为[D/Gmax,D/Gmin]；跨50×时标记“待确认”，未知G或D时标记“待评估”。补测缺口是有效碱基需求，原始产出需求应结合实际有效率另算。

例如G约800 Mb、有效D=30 Gb，则37.5×，未达到用户最低要求，至少还缺10 Gb有效HiFi；D=40 Gb才达到50×。不足时仍可先做探索性初组装帮助调查，但不能写作数据量验收通过。达50×也不保证重复区解决、覆盖均匀或组装正确，仍做多维QC；多倍体需另评各hap覆盖和目标。

## 4. HiFi 个体 A，Hi-C 个体 B：把用途分开

**结论：不能默认视为同个体联合数据；在条件合适时，可研究性地用于保守的挂载，但不能据此认定解析了 A 的真实全基因组单倍型。**这是本项目的条件性建议。CiFi 研究指出，组装、分型和挂载数据理想情况下应来自同一个体，以减少分析复杂度。[CiFi 原始研究](https://www.nature.com/articles/s41467-025-66918-y)

“不同个体一定不能挂载”也过于绝对。蚊虫研究明确使用不同个体的 PacBio 与 Hi-C 数据，并分析挂载结果；同一研究也观察到跨端粒过度合并需人工校正。因此它证明有实践案例，不证明任意物种或不同群体都安全。[GigaScience 研究，Table 2 与结果](https://academic.oup.com/gigascience/article/doi/10.1093/gigascience/giag061/8690708)

### 决策表

| 数据关系 | 本项目处理建议 |
|---|---|
| A 与 B 为同个体不同组织/建库 | 优先方案；仍检查组织/细胞系异常、文库质量和标签，不能只凭物种名合并 |
| 同一克隆或高度近交品系的不同个体 | 遗传差异可能较小，但需确认来源、性别和核型；明确记录仍非同个体 |
| 同物种不同个体，群体/性别相同 | 先独立得到 A 的 HiFi 基线，再尝试 B 的 Hi-C 挂载；局部结构冲突逐项审查 |
| 性别不同或核型未知 | 性染色体单独处理；B 缺少的 Y/W 无法因“无 Hi-C 支持”判为污染或删除 |
| 不同群体、结构多态性明显、杂交/多倍体 | 高风险；优先补 A 的数据；不把 B 的结构自动当作 A 的结构 |
| 不同物种，或来源不明/混合样本 | 当前规范不直接作为常规自动挂载/分型输入；保留为单独的探索性证据 |

这些类别没有通用 SNP 差异率、比对率或 MAPQ 数字能一刀切放行。Hi-C 的非均匀采样、重复序列和限制性位点偏倚，会影响不同区域的信息量。

### 有 B 的 Hi-C、暂时无法补 A 时的具体步骤

1. **记录来源。**保存 A/B 的物种、个体、群体、性别、倍性、核型及建库方法。条形码能帮助发现误鉴定，但不能证明核基因组结构相同；比较可靠、可比区域的基因型只能提供样本一致性线索，不能忽略 Hi-C 的采样偏倚。
2. **先做 A 的 HiFi 基线。**默认先以 A 组装 contigs 并评价，保留此版本。本项目不默认把 B 的 Hi-C 喂进 hifiasm 解释为 A 的染色体分型；若实验探索此模式，需独立分支和专门的分型验证。
3. **B 比对到 A 的指定版本。**按建库类型处理 chimeric junction、双端、去重与排序，保存有效独特联系、重复率、覆盖分布等；Hi-C 不是普通 WGS 配对。Omni-C 不机械套 GATC。高 mapping rate 只说明部分可比对，不能排除局部结构不同。
4. **挂载结果作为待审候选。**检查全图及局部图、多个分辨率、未归组 contigs 和性染色体。跨群体的真实倒位/易位可能表现成与 A 冲突的联系；过滤低 MAPQ 不能消除这种生物学差异。
5. **区分 contig 内错误与 scaffold 连接。**如果 B 的图要求切开 A 的一个 HiFi contig，先核查 A 的独立长 reads 是否跨越疑点、局部图结构及重复比对。若 A 有强支持而 B 冲突，保留个体结构差异假说，不自动切断。相反，跨 N-gap 的正常挂载本来就可能没有 A reads 跨越整个缺口，不能把“没有跨 gap reads”一律判错。
6. **解决不了就保留不确定性。**争议连接拆开或标记待验证，争取 A 的 Hi-C、光学图谱/遗传图谱等独立证据。最终明确序列来自 A、长程信息来自 B；这不是已验证的 A 亲本级结构。

用 B 的普通 WGS 来给 A 做 polishing/QV 也不是补救办法：个体真实变异会被混入错误判断。Hi-C 文库本身因覆盖偏倚，也不作为默认的全基因组 k-mer 准确度评价替代品。

## 5. 看到异常后怎么判断

以下是需要进一步核查的**候选解释**，不是图形自动诊断规则。

| 现象 | 候选解释 | 下一步 |
|---|---|---|
| BUSCO 很高、scaffold N50 很大，但接触图有强烈断裂/跨组信号 | 错连接、真实重排、重复映射或非同个体冲突 | 查看局部原始联系和 A reads；对照连接位置、样本和重复区 |
| assembly 偏大、D 高、某些 contig 深度约常规一半 | 未分离冗余等位序列，也可能为真复制/性染色体 | 联合 self-alignment、k-mer 拷贝、性别/倍性信息；不要仅按深度删 |
| assembly 偏小、部分区域深度异常高 | 重复塌缩，也可能是细胞器或映射偏倚 | 联合组装图、可靠 k-mer、基因拷贝与分类 |
| 少数 contig 无 Hi-C 联系 | 文库信息不足、重复、性染色体、细胞器、污染等 | 结合 A reads 和分类检查；保留未定位类别 |
| 与近缘参考结构不一致 | 真正演化/个体差异、参考错误或本次误拼 | 参考只是比较证据，不能强行改成同样顺序 |
| purge 后 N50/BUSCO 单拷贝比例提高，但完整度下降 | 可能误删真实独有序列 | 检查移除 FASTA、hap 特异 k-mer 与基因；可恢复旧版 |

用来挂载的同一份 Hi-C 再画图，适合自洽检查但不是独立验证。条件允许时增加独立来源证据。VGP 原始研究展示了多平台组装与错误审查，也说明跨技术的一致支持对结构判断很重要。[VGP 原始论文](https://pmc.ncbi.nlm.nih.gov/articles/pmid/33911273/)

## 6. 后续每个 assembly 的固定报告

至少记录：交付角色/目标、样本关系、预期规模与倍性证据、contig/scaffold 长度统计和 N/gap、逐 hap 与合集的 k-mer/基因指标、深度/拷贝异常、污染分类依据、接触图及争议连接清单、校正前后变化、可用分型证据、未覆盖/未验证区域。所有指标绑定准确的 FASTA 摘要和评价数据库版本。

最终结论写成“哪些维度有支持、哪些区域有疑点、哪些暂时无法验证”。不凭一项分数把全基因组概括为绝对正确，也不为达到预设染色体数量强制连接。具体软件执行契约见[19](19_全基因组组装编程与验收规范.md)。

## 7. 如何判断组装受重复区限制

2026-11-01追加。重点是“长且高度相似的重复使当前reads无法辨别拷贝并连接两侧”，不能仅凭重复比例高或N50低下结论。短而分化的重复即使占比高，也可能很好组装；少量超长高一致性重复也能造成关键断点。重复长度、相似度、排列和可跨越的分子信息共同决定困难程度。[重复解析原始研究](https://www.nature.com/articles/s41467-019-13355-3)

### 7.1 证据检查顺序

1. **排除数据与运行问题。** 先复核用户≥50×有效HiFi门槛、G范围、读长分布及局部覆盖；检查输入完整、软件退出、资源与参数。达到平均50×不排除局部缺失，也不意味着每hap50×。
2. **调查重复倾向。** 用meryl/KMC计数、GenomeScope拟合检查高拷贝成分与模型适配，排除细胞器/污染高峰。模型的重复估计受k、截断与倍性影响，不能等同RepeatMasker的注释比例。
3. **观察初组装与原始图。** 保留hifiasm unitig/assembly GFA，查看疑似重复节点是否连接多个不同侧翼、是否存在无法唯一选路的分支/回路。杂合、多倍体和测序错误也产生复杂图；分支数量不能自动当重复量。
4. **把困难位置与重复对上。** 初组装可用RepeatModeler构建TE库，再用RepeatMasker定位；串联重复、大片段自同源还需相应分析。比较contig末端附近与可比内部窗口的重复富集，记录疑似连接两侧。末端窗口宽度属于分析参数，不是通用诊断阈值。组装中已经缺失/塌缩的重复会使注释比例低估，不能用“注释重复少”排除困难。[RepeatModeler官方说明](https://www.repeatmasker.org/dev/RepeatModeler/)
5. **检查原始分子和拷贝支持。** 同个体HiFi回贴并自比对，检查独立reads是否能跨整个疑点并可靠锚定两侧。联合高拷贝k-mer、图与局部异常深度判断塌缩；多重比对、MAPQ过滤和同源hap会改变深度，2倍/3倍只能作线索。记录所用primary/hap产品和单拷贝基线。

### 7.2 工作判断与后续行动

若数据质量与覆盖合理、断点集中于长高相似重复、图在相同位置无法选路、且缺乏可靠跨越分子，可报告“现有证据支持长重复为主要瓶颈”，并列出位点及其他解释。不能证明全基因组困难都由重复造成。

例：HiFi主要为15–20kb，而某位置存在约80kb近乎一致的重复块；即使50×以上，继续增加相同长度reads也未必补充足够的拷贝归属信息。但较短且带有可辨差异的重复可能通过重叠信息解析，因此不是所有重复都必须被单条read完整跨越。应检查实际读长尾部、拷贝差异与图路径，而不是只比较read N50和一个重复长度。

局部低覆盖优先补有效数据；长重复且没有跨越信息时，评估更长分子/超长reads及能利用其信息的组装方案；杂合或倍性复杂时走分型/倍性适配。Hi-C可辅助归组和挂载，不能自动补出缺失的重复碱基、证明其拷贝数或把gap变成完整contig。

后续报告必列：重复估计方法和范围、主要长重复类型/长度/相似度、疑似断点与图节点、跨越reads支持、深度/拷贝证据、与覆盖/杂合/倍性解释的区分，以及补测或保留未解决区域的方案。当前没有用户数据，以上是诊断方案，尚未对具体基因组作判断。
