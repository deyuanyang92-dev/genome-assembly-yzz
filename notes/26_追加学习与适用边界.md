### 阅读后落实的限制

| 场景 | 发现的问题或边界 | 本项目采用的规则 |
|---|---|---|
| HiFi质量 | ONT质量过滤、HiFi rq标签和FASTQ碱基质量不是同一概念 | 保留平台、导出与过滤依据，不套统一Q阈值 |
| 参考一致性 | alignment-validation示例抽取并排序M5，丢失SN与M5对应关系 | 检查参考摘要及有序SN/LN/M5（可用时）；不只比较MD5集合 |
| 覆盖率 | idxstats的比对数/序列长度不是每碱基覆盖；只平均有覆盖位置会忽略零覆盖 | 报告明确分母的碱基深度、覆盖广度和零覆盖区 |
| 比对过滤 | primary不等于唯一定位，MAPQ筛选也受比对器模型影响 | 按长读/Hi-C和任务选择过滤；保留原始比对与规则 |
| 排序 | 简单逐行检查位置递增若每换contig就重置，不能排除同一contig再次出现 | 同时检查参考字典次序、contig连续性及坐标 |
| 去重 | 普通双端文库的去重统计和经验阈值不能直接推广至长读或不同Hi-C协议 | 保留过滤前后统计、文库方法与有效独立分子信息 |
| 分型 | BAM的HP/PS、VCF的GT/PS和组装hap文件表达不同层次 | 记录分型区块和证据，不把局部hap编号冒充全基因组父母标签 |
| 工作流模板 | Snakemake示例all目标为results路径，align规则产物为aligned路径，交接不一致 | 先核对真实DAG与命名，模板不得直接用于正式组装 |
| 缓存 | Nextflow模板的lenient建议不能无条件作为文件变更的修复方案 | 先验证内容身份；缓存策略、内容摘要及工具版本同时记录 |
| Hi-C质量 | 未挂载contig间的trans联系可能来自同一条染色体 | 不按人类完整参考的cis/trans比例阈值删除跨contig有效联系 |
| 接触矩阵 | bin、坐标、参考次序、归一化权重和缺失值决定图能否比较 | 换版后重建或验证转换；NaN不能自动当作零联系 |
| 可视化模板 | API版本、返回数组维度和shell续行必须进一步核对 | 未验证示例不能列入正式可执行脚本；图漂亮不等于结构正确 |

这些是文本与逻辑核查结论；没有把新增示例逐一执行。数值验收统一采用[23](23_EBP2026规范与本项目对标要求.md)，技能模板中的覆盖或人类阈值不覆盖用户50×要求。

## Colora运行准备及当前阻碍

已补读common、HiFi prep和hifiasm规则。默认全流程目标需要Hi-C，并包含核、细胞器与多项QC；不能把默认all目标当成HiFi-only入口。diploid_mode和purge_dups的组合受源码限制。官方HiFi测试文件以二进制分片提供，应先正确合并再解压/读取。
