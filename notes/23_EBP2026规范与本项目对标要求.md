# EBP 2026规范与本项目对标要求

核查日期：2026-11-01。正式基线是EBP委员会2026-01-31批准的Assembly Standards v7.0与Recommendations v4.0；不是国际强制性法规，也不是任一期刊的通用录用保证。

## 1. 外部基线

普通、材料足够的真核参考基因组，EBP最低目标是 **6.C.Q40**：Mb级contig N50、染色体尺度scaffold N50及Q40准确度；另列 **k-mer完整度>90%、候选染色体挂载>90%、假重复<5%、保守单拷贝基因完整且单拷贝>90%、同一生物来源的转录本可比对>90%**。基因指标需结合谱系与倍性解释，不能把BUSCO D直接当假重复比例。低输入有5.C.Q40等分级；T2T的C.C.Q60不是普通项目默认要求。污染与细胞器分离、明确产品角色、结构审查和原始数据公开也是交付的重要部分。[EBP标准原文](https://www.earthbiogenome.org/report-on-assembly-standards)

术语核对：标准页用N50，建议页也使用contig NG50描述目标。因此我们的报告应同时列N50、NG50及NG50的基因组大小分母，不悄悄互换。C代表达到染色体尺度，不是“只有一条scaffold”。

## 2. 数据规划参考

EBP建议HiFi每hap >12.5×、理想至20×（二倍体总量相对单套长度>25×）；挂载Hi-C相对单套长度>50×。这些是经验起点，不是保证。长reads及polishing reads来自单个个体；Hi-C优先同个体，受限时可用同物种其他个体/混样，尽量同性别。建议在组装后进行curation、重映射及QC，而不是把自动挂载当终点。[EBP建议原文](https://www.earthbiogenome.org/report-on-assembly-recommendations)

**项目解释：**这些覆盖量必须先说明分母、过滤前后和有效分子，不能把Hi-C 50×解释成每个区间都有均匀50×有效联系。个体差异的结构冲突、混样复杂度和低输入扩增偏倚按21单独记录；高覆盖不能替代样本身份核查。

## 3. 项目高标准验收表（2026-11-01 按用户要求升级）

用户明确要求：流程必须包含近期标准论文要求，原则上显著高于最低标准。因此后续默认以本节“项目目标”规划和检查，不能达到外部底线就结束。尚无用户数据，所有状态均为“待测”。项目目标由我们制定，不冒充论文统一要求；外部标准、项目目标、实际测量、证据充分程度必须分列。新论文及适用性见[25](25_近期标准论文与项目高标准验收.md)，供后续编程读取的配置见[质量策略](../config/assembly_quality_policy.json)。

| 项目 | 项目目标 | 进一步争取 | 适用条件与证据 |
|---|---|---|---|
| 有效 HiFi 覆盖 | **≥50×，用户硬门槛** | 根据缺失与覆盖偏倚决定是否补测，不盲目加量 | D/G；二倍体不是每 hap 50×；G 有范围时用最保守覆盖判定 |
| contig 连续性 | N50、NG50 均争取 ≥10 Mb | ≥20 Mb或接近染色体长度 | 对短染色体物种用接近其真实染色体尺度的目标并预先注明；NG50 分母有证据，不能用组装总长替代 |
| 碱基 QV | **≥50** | ≥60 | 相对 Q40 分别降低约10倍、100倍估计错误率；须注明数据是否独立、k和覆盖，不能把非独立QV当独立验证 |
| 可靠 k-mer 完整度 | **≥98%** | ≥99% | 必须符合交付产品的可表示范围；两个完整 hap 合集评价全部可靠核 k-mer；单个 hap 不要求包含另一个 hap 的特异 k-mer |
| BUSCO 基因组模式 C | **≥98%** | ≥99% | 同时列 S/D/F/M、谱系及版本；有生物学依据为单拷贝的产品另争取 S≥95%；多倍体和真实复制不强删来提高S |
| 染色体挂载 | **≥98%** | ≥99% | 适用于染色体级交付；全套目标核序列作分母，染色体级但未定位的 unlocalised 部分另列；保留未挂载序列 |
| 假重复 | **≤1%** | ≤0.1% | 定义评估单位和分母，结合k-mer拷贝、深度与自比对；BUSCO D不是假重复率，不同单位不能混比 |
| 缺口密度 | **≤100 gaps/Gb** | ≤10 gaps/Gb | 我们的工程目标；并列绝对数量、N碱基数/比例；实际重复区复杂度优先于数字 |
| 转录本可比对 | **≥98%** | 检查未比对部分原因 | 仅在有合格同物种/来源明确的转录本时评价；序列比对率不能代替剪接和基因模型准确性；无数据记待评估 |
| 已确认结构错误 | **已发现且高置信度的错误全部处理** | 关键连接增加独立支持 | 已处理不等于全基因组零错误；保留争议区，不以总N50掩盖局部错连 |

这张表是多目标验收，不计算一个能互相抵消的总分。**50×为硬门槛，其余为默认高目标；未达到必须报告差距和原因，不能静默放宽并称“全部达标”。** 物种例外、技术限制及证据不足必须单列，报告可保留为阶段成果，但不能升级为完整高标准交付。

### 3.1 不能仅用数值替代的验收动作

| 维度 | 项目记录与验收动作 | 达不到时怎么处理 |
|---|---|---|
| 样本与目标 | 个体/物种/性别/倍性、primary还是两hap，明确HiFi/Hi-C关系 | 关系未知标unknown，不自动跑同个体分型分支 |
| HiFi数据量（用户硬性要求） | 有效HiFi碱基量/单套核基因组大小≥50×；调查和初组装后复核，报告估计范围 | 不足时明确未达标并给出有效碱基补测缺口；大小不确定时不强行判通过；可先探索性初组装 |
| 连续性 | contig与scaffold分列N50/NG50、gap数和N数，按本节高目标检查 | 先找数据缺口、重复图或误连接；不靠加N/强连提高成绩 |
| 碱基质量 | 按正确个体/口径计算QV并保存k与reads来源；争取Q50以上作为提升目标 | 检查评价偏倚、局部错配与模型，再决定是否polish |
| 完整度与拷贝 | 可靠k-mer、BUSCO C/S/D/F/M，逐hap及合集；争取相近物种优秀水平 | 查真实倍性、haplotigs/塌缩、谱系预测；不用单一D或总长删序列 |
| 挂载 | 全部目标核序列为分母，保存未挂载部分；按本节98%/99%目标检查 | 保留未定位序列，不删掉难挂载部分美化比例 |
| 结构 | 全图/局部图、多分辨率、争议连接表，独立证据可用则加入 | 拆开或标记不确定连接；参考差异不自动判错 |
| 分型 | 明确模式与证据；有真值才报告相应switch/hamming等指标 | 不以hap1/hap2文件名冒充全基因组父母来源 |
| 污染/细胞器 | 分类、GC/深度、邻接支持联合；保存剔除序列和原因 | 不因一次命中直接删除潜在内源序列 |
| 校正及最终交付 | edit清单、版本摘要、最终AGP/FASTA重建、最终参考绑定QC | 任一产物换版需重新核对所有关联坐标/评价 |
| 复现 | 环境、源码SHA、参数、数据库、日志、原始reads和结果入口 | 缺少部分标出，不能称完整复现 |

对于高度分歧谱系/多倍体，调整生物学解释并记录依据，而不是把参数换到“看起来通过”。

### 3.2 产品角色、困难区域和独立证据

- primary/pseudo-haploid、alternate、完整hap1/hap2分别评价；不能将两个hap串接后，用加倍长度和N50声称单套组装优秀。逐hap完整度与两hap合集完整度并列，说明杂合位点可表示范围。
- 逐条检查端粒、rDNA、候选着丝粒、异常高/低深度区、性染色体及覆盖缺口。环节动物不能默认套用植物端粒序列或以植物LAI阈值普遍验收；串联重复候选也不等于功能着丝粒验证。
- Hi-C全图、染色体局部图、多分辨率审查及HiFi重映射是常规要求；Hi-C不是独立物理核型证明。染色体数应与核型文献或实验交叉检查。重大融合、裂分、易位等结论争取核型/FISH、遗传图谱或其他独立证据；缺失时降低结论强度，不声称已实验验证。
- 非同个体Hi-C单列供体身份和结构差异风险。冲突优先回查目标个体HiFi，不能直接用供体结构覆盖目标个体，也不能据此宣称目标个体全局亲本分型。
- 已确认污染、接头和不合理末端N必须处理；细胞器与共生体单独识别和建档。按提交规范将细胞器正确关联/纳入相应交付，不因“核组装分开统计”而遗漏细胞器提交。
- T2T作为单独的进阶产品声明：逐染色体无gap、适用的端粒证据、重复区跨越和拷贝数支持、结构与QV证据共同成立。高QV、两端端粒或无N中的任何单项都不够。端粒非经典或染色体特殊结构需生物学解释。

### 3.3 报告和流程出口

每项记录 `baseline / project_target / observed / status / evidence / applicability / limitation`。状态为 `pass / below_target / pending / not_applicable / exception_documented`；缺数据不可写pass，not_applicable必须有理由。证据独立性另设字段，不用一个pass掩盖证据不足。

流程输出分别标记：数据量门槛、外部参考基线、项目高目标、结构审查、分型声明、复现与公开资料；不生成笼统的“高质量=true”。只有HiFi时可交付经过评价的contig组装，染色体级指标和全局分型仍待补证据。组装、清理、挂载、人工修改各阶段存快照；**最终验收绑定最终FASTA的SHA256**，坐标改变后重建相应图谱和评价。公开包包含reads、样本身份、FASTA/AGP/GFA、指标原始表、争议区、人工编辑记录、版本/参数/数据库和运行日志，并按适用要求提交INSDC。

## 4. 统一的实施顺序

样本登记和调查 → 目标个体初组装 → 记录基础QC → 有证据的去冗余/清理及细胞器分离 → 合适数据挂载 → 人工审查并保留修改记录 → 最终多维评价 → 数据与流程归档。污染丰度高时可考虑清理reads后重组装；实际分支由数据决定。

为便于后续编程，每阶段输出都绑定输入身份与FASTA版本，见19；阶段QC缺失不得写作通过。需要把“已计算”“已验证文件一致性”“已审查结构”“有独立证据”分别记录。

## 5. 从论文迁移时的限制

先确认对方的覆盖分母、assembly角色、评价reads是否独立、BUSCO谱系和版本、挂载比例分母及人工修改内容。论文显示完整度高，不代表我们下载到的脚本包含每一步；论文称T2T scaffold，也要检查内部是否有gap。发表年份新，使用的软件仍可能很旧，必须按方法和代码逐项核对。

当前是建立对标规范，未对用户数据打分，也未证明六套完整流程在本机端到端跑通。

> 2026-11-02路线范围补充：HiFi≥50×适用于采用HiFi的路线；用户另要求支持二代组装，不因无HiFi自动拒绝。二代初装＋参考/Hi-C/图谱的条件、交付名称和独立验证见[48](48_二代数据与参考辅助染色体组装路线.md)，最终质量目标仍需逐维评估。
