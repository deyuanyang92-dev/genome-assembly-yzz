# Genome assembly learning library instructions

For genome assembly, polychaete genomics, and related software tasks, first consult `AI_CONTEXT.md`, then follow its links to the smallest relevant set of project notes and version ledgers. Check prior recorded version/scope before repeating software learning. Treat evidence status and limitations as required data. Record new versions, timestamps, input provenance, commands and outcomes in the ledger. Keep the canonical knowledge in Markdown/TSV/JSON so it can be used by multiple coding agents.

For unrelated tasks, do not load the genomics references unless they are relevant.
