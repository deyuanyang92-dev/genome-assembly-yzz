# 基因组组装核心工具速查

> 流程是把工具串起来，真正决定结果的是每一步用什么工具。本表按组装步骤列出最常用的工具。
> **版本号是 2026-10-26 在各仓库 GitHub Releases 页面核对的**（"→ sanger-tol" 表示 sanger-tol/genomeassembly 1.0.1 实际使用的 bioconda 版本）。

## 0. 先看数据类型：怎么选路线

| 你的数据 | 推荐路线 | 现成流程 |
|---|---|---|
| **HiFi + Hi-C**（目前主流的参考基因组方案） | hifiasm（Hi-C phasing）→（purge_dups）→ YaHS → 人工校正 → 去污染 → BUSCO/Merqury | sanger-tol/genomeassembly、VGP（Galaxy）、EBP-Nor |
| HiFi + ONT 超长读长 + Hi-C 或 trio（目标 T2T） | Verkko，或 hifiasm `--ul` → 挂载和校正 | Verkko、sanger-tol（UL 模式） |
| 只有 ONT（± Hi-C） | Flye / NextDenovo / hifiasm `--ont` → 抛光（Medaka、Dorado、NextPolish）→ purge_dups → YaHS / 3D-DNA / HapHiC | nf-core/genomeassembler、CNAG CLAWS |
| 只有 Illumina 短读长 | MaSuRCA / Platanus-allee / SPAdes（小基因组）→ 连续性有限 | –（做参考基因组的话，建议补测长读长） |
| 多倍体或高杂合 | 按等位基因区分的挂载：HapHiC / ALLHiC | –（sanger-tol 已计划支持） |

> 做系统发育（比如提取 BUSCO 直系同源基因）不一定需要染色体级组装，短读长组装的 BUSCO 完整度够用就行。要发表参考基因组，HiFi + Hi-C 基本是标配。

## 1. 基因组调查（组装前：估计大小、杂合度、倍性、覆盖度）

| 工具 | 最新版本 | 用途 | 备注 |
|---|---|---|---|
| GenomeScope 2.0 | v2.0.1（GitHub）；→ sanger-tol 用 2.1.0 | 用 k-mer 频谱拟合基因组大小、杂合度、重复比例 | 输入是 Jellyfish、KMC 或 FastK 的直方图 |
| Smudgeplot | v0.5.4（2026-02） | 推断倍性 | 和 GenomeScope 配套使用 |
| FastK | v1.2（2026-01） | 速度很快的 k-mer 计数（Gene Myers） | sanger-tol 用它建库，配合 MerquryFK |
| Meryl（Merqury 自带） | 随 Merqury v1.4.1 | k-mer 计数 | VGP 用的是这一套 |

## 2. 组装器

| 工具 | 最新版本 | 适用数据 | 特点 |
|---|---|---|---|
| **hifiasm** | 0.25.0（2025-03）→ sanger-tol 同版本 | HiFi（主）；ONT `--ont`；UL `--ul`；Hi-C phasing；trio | 当前 HiFi 组装的事实标准，能直接产出分型组装；sanger-tol、VGP 都以它为核心 |
| Verkko | 见笔记 06 | HiFi + ONT UL（± Hi-C、Pore-C、trio） | T2T 级别；资源消耗大 |
| **Flye** | 2.9.6（2025-05） | ONT、PacBio CLR、HiFi | 基于 repeat graph，ONT 组装的经典工具，也有宏基因组模式 |
| **NextDenovo** | 2.5.2（2023-03） | ONT、CLR | 先纠错再组装，大基因组上效率高，国内用得很多；常和 NextPolish 搭配 |
| Canu（HiCanu） | v2.3（2024-12） | ONT、CLR；HiCanu 用于 HiFi | 经典的"纠错 → 修剪 → 组装"三段式，速度慢 |
| Shasta | 0.14.0（2025-01） | ONT | 速度极快，组装质量一般 |
| wtdbg2（RedBean） | v2.5（2019-09） | ONT、CLR | 很快，但已多年没有更新 |
| MaSuRCA | v4.1.4（2025-06） | Illumina（± 长读长，混合组装） | 基于 super-read；只有短读长时可以考虑 |
| SPAdes | v4.3.0（2026-06） | Illumina（± 长读长） | 适合细菌、细胞器、小基因组，不适合大型真核基因组 |

## 3. 抛光（Polishing）

| 工具 | 最新版本 | 用途 |
|---|---|---|
| NextPolish | v1.4.1（2022-07） | 用短读长或长读长抛光 |
| Medaka | v2.2.2（2026-05） | ONT 官方的一致性序列校正 |
| Dorado | v2.1.2（2026-08） | ONT 碱基识别软件，带 `polish` 子命令 |
| Pilon | v1.24（2021-01） | Illumina 抛光，比较老 |

> HiFi 组装的准确度已经很高（QV 通常 > 50），一般**不需要再抛光**。sanger-tol 和 VGP 都没有设置常规抛光步骤，sanger-tol 只保留了遗留的 10X 抛光。

## 4. 去冗余（Purging）

| 工具 | 最新版本 | 用途 |
|---|---|---|
| **purge_dups** | v1.2.6（2022-06）→ sanger-tol 同版本 | 根据读长覆盖度和自比对，去掉主组装里多余的 haplotig |
| purge_haplotigs | – | 同类老工具 |

> 用 hifiasm 做 Hi-C 或 trio 分型时，hap1/hap2 已经分开了，**通常不需要再去冗余**。去冗余主要用在 pri/alt 模式，以及 Flye、NextDenovo 这类不分型的组装。

## 5. Hi-C 挂载与人工校正

| 工具 | 最新版本 | 特点 |
|---|---|---|
| **YaHS** | v1.2.2（2024-09）→ sanger-tol 同版本 | 速度快、准确，sanger-tol 和 VGP 都用它 |
| 3D-DNA + Juicer | 见笔记 07 | DNA Zoo 的经典方案，配合 Juicebox Assembly Tools 做人工校正 |
| **HapHiC** | v1.0.7（2025-06） | 区分等位基因，不需要参考基因组，适合多倍体；国内植物基因组常用 |

| SALSA2 | v2.3（2021-06） | 比较老 |
| **PretextView** | 1.0.7（2026-04） | 在 Hi-C 图上人工校正（ToL 和 VGP 的标准做法） |
| Juicebox（JBAT） | – | 校正 3D-DNA 生成的 `.hic` 和 `.assembly` |
