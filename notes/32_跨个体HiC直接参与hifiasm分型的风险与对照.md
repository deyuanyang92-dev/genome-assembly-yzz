# A的HiFi＋B的Hi-C直接进入hifiasm：风险与评估

2026-11-01。针对用户明确的“同种、非同个体HiFi和Hi-C一起导入hifiasm”，补充[31](31_非同个体HiC贡献与干扰评估.md)。依据固定hifiasm ec9a8b2（0.25.0-r726）的README、`docs/source/hic-assembly.rst`、CLI及`hic.cpp`选段。没有真实样本验证，下面是机制判断和项目对照设计，不是已测得的错误率。

## 1. 核心区别

HiFi来自目标个体A，Hi-C来自同种个体B；正确接口为HiFi放位置参数、Hi-C放`--h1/--h2`。不能把Hi-C FASTQ与HiFi拼接后一起当作高准确长reads。

进入hifiasm的Hi-C并非只用于最后的染色体挂载，而是参与将A的组装图划分为单倍型。因此，与先用HiFi组装、再由B Hi-C提供挂载建议相比，其影响更早进入分型/contig生成过程。输出依旧主要由A的HiFi构建序列，但路径与相位选择可能受B影响；这不是简单把B的序列拼进A，也不意味着所有结果必然错误。

## 2. 有哪些缺点

1. **相位关系不匹配。** A和B的杂合位点、共享等位基因及其长程组合可能不同。即使核型一致、没有明显大SV，也不能用B的联系证明A的单倍型。
2. **基因型差异造成定位偏倚。** B部分read难以定位到A的等位序列，或更容易定位某一等位拷贝；可造成链接不足/偏斜，影响分型完整性与稳定性。
3. **结构差异造成冲突。** 倒位、易位、融合/裂分、CNV、性染色体差异与倍性差异可能干扰相关区域的路径/相位判断；并不是这些差异必然触发某种固定错误。
4. **影响不只限于最终hap标签。** 当前源码`hic_short_align`包含可选`update_switch_unitig`处理，不能假设Hi-C始终只给已固定contig贴标签。实际影响还依赖组装模式和开关。
5. **常规QC可能发现不了。** 相位切换可以保持局部碱基准确、基因齐全和总长度正常，故高QV/BUSCO/N50不能证明A的分型正确。hap1/hap2相近长度也不是相位真值。

相位不匹配的示意：两个相距较远、都为0/1的位点，A的两条同源染色体组合为`00 / 11`，B为`01 / 10`。B中的真实Hi-C联系若被解释成A的相位证据，会与A冲突。此示例只说明风险机制，实际hifiasm还结合HiFi及图信息，不表示必然照B输出。

同一个体Hi-C也无法天然给不同染色体统一标父源/母源，hifiasm文档明确跨染色体亲本来源可能混合；跨个体时更不能把hap1/hap2称为A的完整父母本基因组。

## 3. 如何评估，而不是只说“有风险”

用相同A HiFi、同一版本、相同基础设置；独立目录和前缀保存，不跨样本复用bin缓存。若有A的ONT，两条分支保持同样ONT输入。

```bash
# 对照：仅A的HiFi
hifiasm -t 32 -o A_only A.hifi.fastq.gz 2> A_only.log
# 探索：A的HiFi＋B的Hi-C
hifiasm -t 32 -o A_with_Bhic \
  --h1 B.hic.R1.fastq.gz --h2 B.hic.R2.fastq.gz \
  A.hifi.fastq.gz 2> A_with_Bhic.log
```

两种模式输出角色不同：primary/alt、HiFi-only的部分分型hap与Hi-C hap不能简单按文件名一一当等价产品。预先声明比较的是primary表示、每hap还是完整二倍体并集，不能直接把A_only primary与两个hap合计长度比较后判断重复/缺失。

| 评估层次 | 实际比较 | 能够得出什么 |
|---|---|---|
| 序列和拷贝保持 | G/预期倍性、总量、每hap与并集k-mer谱、缺失/冗余、QV、BUSCO及深度 | 检查是否丢失/多拷贝/质量退化；不能证明相位正确 |
| 局部路径与结构 | 两分支差异比对、变化断点/分支、A HiFi及同个体ONT跨越、竞争路径与重复区 | 检查B引入的改变是否与A证据冲突；read无法跨越的尺度不能据无支持直接判错 |
| 分型是否符合A | A的适用亲本hap-mer、A独立相位标记/Strand-seq/同个体Hi-C；A长reads可检验其覆盖范围内的局部相位冲突 | 有适用真值才估switch error/相位块；没有真值只能报告局部一致性、冲突和未验证尺度 |
| 稳定性 | B按完整接触分子抽样/不同seed，记录相位块、同源位点分配与结构变化 | 不稳定提示不足/冲突；hap标签可整体翻转，比较前按块对齐标签，不能把全局0/1交换当switch错误 |

A_only也不是相位真值：HiFi-only往往只能局部分型，因此不能把相对A_only的所有改变都叫“错误”。两套结果若都由A reads生成，回比A reads属于自洽性，独立评价数据与既有组装数据应分别标识。A的同个体长reads不足以跨越长相位区间时，不能凭局部匹配宣布整条染色体分型正确。

B的高mapping率、同一B文库的漂亮接触图、B留出集支持、不同工具用同一B数据得出一致结果，都不能排除B与A存在系统性的相位/结构差异。没有A的相位真值时，不能报告“跨个体Hi-C没有引入分型错误”。

## 4. 当前建议

- 单个体参考项目优先A HiFi（±A ONT）组装，B Hi-C作为后续受控挂载证据，按31审核；这种分离便于保留原contig并撤销可疑连接，但也不保证跨个体挂载一定正确。
- 直接加入B Hi-C可以保留为探索/比较分支，尤其需检查跨个体差异；没有额外证据时不作为默认的“已验证A染色体级分型”交付。
- 若核心目标是可靠重建A的两套单倍型，优先补A自身Hi-C或适用的A亲本/其他独立分型数据。对明显高度近交、低多态样本，个体差异风险可能更小，仍需实测，不能把同种或同品系等同于同基因型。

EBP允许其他同种个体Hi-C用于挂载，并不等于证明这种数据适合直接充当A的分型真值。以上建议是基于数据来源与算法用途作出的项目判断，尚未有本项目真实样本对照结果。
