## 数据来源和可重复命令

在仓库根目录运行。网络下载可能依赖当前主机代理；此次 WSL 有无效代理/DNS问题，使用直接 `curl`/`git clone` 命令可访问，公众号需 Windows 请求。不要复制旧机器的代理地址。

- hifiasm：官方 README 指向 [chr11-2M.fa.gz](https://github.com/chhylp123/hifiasm/releases/download/v0.7/chr11-2M.fa.gz)，这里保存为 `test_data/hic-study-chr11-2M.fa.gz`；数据来自旧 release，执行程序是当前固定 SHA。
- YaHS：官方 `scripts/run_test.sh` 指向 [Zenodo 7079219](https://zenodo.org/records/7079219)，下载 `LYZE01.contigs.fasta.gz`、同名 `.fai`、`LYZE01.hic.bed.gz`。API 内容地址为 `https://zenodo.org/api/records/7079219/files/<文件名>/content`。
- 文件 SHA-256 见 [fixture_checksums.sha256](../tests/learning_smoke/fixture_checksums.sha256)。校验和在下载后记录，用于锁定本次数据；不是与作者独立签名交叉验证的证明。

## 本次观察到的结果

hifiasm 运行参数 `-f0 -t4`，日志报告约 98.892 s、峰值 RSS 0.407 GB。primary GFA 含 1 条 segment、2,217,142 bp；两条 hap GFA 分别 2,217,142 和 2,221,193 bp。该运行没有 Hi-C 输入，不能当作 Hi-C 分相或拟南芥挂载测试。

YaHS 输入 198 条 contig、12,431,314 bp；输出 107 条 scaffold、12,441,214 bp，日志 N50 为 803,688 bp。增加 9,900 bp 为 gap；输出保留全部 12,431,314 个 A/C/G/T 碱基。已独立用 AGP 重建 FASTA 并按序列名称/序列比较一致，进一步核查 component 区间和方向。

YaHS 日志有 `assembly N50 ... too small. End of scaffolding` 和提示“若有内存问题可增加内存”；实际退出码为 0。本次保留原始日志，不将提示本身断言为 OOM。该碎片化样例的结果不等同于已获得完整染色体。

`juicer pre -a` 处理 1,023,994 对 links，scale factor=1；再以未修改的 `.assembly` 运行 `juicer post`，执行成功。没有运行 Java juicer_tools 生成 `.hic`，没有进行 Juicebox 人工校正。因此结论只是 JBAT 数据交接和往返转换通过。

benchmark 的实测结果与源码问题详见 [notes/11](11_HiC_scaffolders_benchmark.md)。保留结果 JSON、命令和人工构造输入；没有在当前机器提交 Slurm 作业。
