# 参考辅助组装：方法体系、工具选择与验收

2026-11-03实测增补：[RagTag三分支人工挂载](../tests/ragtag_scaffold_2026-11-03/README.md)已执行固定v2.1.0源码，验证AGP独立重建、方向、默认/推断gap、未定位组件保留及参考重排偏倚。以下“本批未运行”指2026-11-02文献批次；其余参考工具及真实目标全流程仍未运行。

更新：2026-11-02。本文修正前面对“二代WGS＋参考”回答过窄、随后又过度转向历史局部组装的两次问题。证据是综述指定章节、方法论文及官方接口核查；本批没有运行这些上游软件，不提供性能排名或生产验证保证。

## 1. 先回答用户的实际问题

已有参考是组装设计的重要输入。**目标reads先生成contigs，再用参考组织染色体，是有效的参考辅助全基因组组装路线**；其中使用从头组装组件，并不意味着整套流程没有使用参考。RagTag正是这种路线的常见候选。与此同时，参考也能提前参与reads分区、布局和再组装，不能只讲最后挂载。

不能从“用户有参考”直接推出所有物种都应先按参考分区组装，也不能用历史方法的存在替代现代可运行性验证。选择取决于目标是恢复样本序列、构建染色体布局还是生成参考坐标共识，以及参考质量、分化、重排、倍性和文库。

## 2. 综述提供框架，原文和接口约束能力

本批综述指定章节和准确题录见[综述复核](sources/reference_assembly_reviews_2026-11-02.md)。Ghurye & Pop (2019)和Rice & Green (2019)说明共线性是合法连接信息，同时讨论与目标真实重排冲突的问题；Li等(2026)用于复核质量和策略框架。另核对Li & Durbin (2024), *Genome assembly in the telomere-to-telomere era*, DOI [10.1038/s41576-024-00718-w](https://doi.org/10.1038/s41576-024-00718-w) 的数据类型及评价章节；它以近T2T长读组装为重点，不能据此排除短读路线。

以下按“参考介入的位置”分类，是本项目综合设计，不是照搬某一综述的分类。具体版本和默认值回到工具手册；例如综述把MeDuSa与Ragout并列谈多参考和树，不能据此认定MeDuSa必须输入系统树。

| 类别 | 参考实际作用 | 代表方法 | 应交付和审查 |
|---|---|---|---|
| reads分区及局部组装 | 将reads定位到参考区域，降低每次组装规模 | Lischer & Shimizu 2017流程 | 局部组装和合并；必须救回未比对reads、审核重复分配和边界 |
| 比较布局/参考辅助再组装 | 用参考约束布局或目标reads图路径 | AMOScmp；AlignGraph | 真实延伸碱基、图路径及其目标数据支持；两工具年代/数据假设不同 |
| 单参考挂载 | 按同源比对确定组件的分组、顺序和方向 | RagTag scaffold、Chromosomer；历史RaGOO | FASTA＋AGP/fragment map＋未定位序列；参考推断连接 |
| 多参考结构推断/整合 | 综合参考间的共线与重排或多布局 | Ragout2、MeDuSa、ntJoin、RagTag多分支＋merge | 参考冲突、权重、组件坐标与来源；各算法不能随意互换 |
| 参考与目标成对证据结合 | 比较推断提供远程候选，目标成对reads支持部分邻接 | RACA；IMAP整套流程 | 预测染色体片段、实际文库跨度支持与未知部分分列 |
| 参考坐标共识 | 在参考布局中表示目标检测到的变异 | 比对→变异→共识工具链 | 单独标明产品；无覆盖mask、参考外序列和杂合表示不能遗漏 |
| 修正/补洞 | 切断疑似错拼，或从另一assembly取得片段 | RagTag correct/patch等 | 断点证据、donor身份、新碱基来源；不同于只排序 |

完整工具输入和版本依据分别见[挂载工具核对](sources/reference_tools_audit_2026-11-02.md)、[参考参与实际组装核对](sources/guided_assembly_audit_2026-11-02.md)。

## 3. 工具选择必须落实到操作

| 工具 | 可取之处 | 主要代价/边界 | 本项目候选定位 |
|---|---|---|---|
| RagTag scaffold | 单参考、接口清楚、输出AGP、实际碱基来自query | 参考特有重排可传到布局；不能恢复gap真实序列 | 高质量合适参考下的布局基线，不是输入FASTQ的初装器 |
| RagTag correct / patch / merge | 分别用于切断、donor填补、布局整合 | 切断可能误改真实SV；patch引入donor碱基；merge要求同组件体系 | 显式选操作，不默认把correct/patch串上去 |
| Ragout2 | 多参考、共线块及重排模型；支持大基因组 | 计算和输入准备更复杂；多态及重复使块推断困难 | 多参考结构推断候选，按输入表示和核型评估 |
| MeDuSa | 多个完整或草图参考，图优化；不用用户提供树 | 原版环境较旧，参考偏差仍在 | 方法对照；另记录MeDuSa2但未证实可直接替代 |
| ntJoin | 加权minimizer图，支持多个参考/初装 | 默认可切断、可修剪重叠，不能假设非N组件原样全部保留 | 大规模参考/多初装整合候选；显式记录cut/overlap和请求AGP |
| Chromosomer | fragment map使定位与组装步骤清楚 | 接口/维护需要验证，不能恢复目标未测碱基 | 可追踪的参考布局候选 |
| AlignGraph | 目标PE＋初装＋参考共同参与实际序列延伸 | 历史依赖、重排和重复误连接需实测 | 参考辅助再组装研究分支，不能与长读AlignGraph2混用 |
| RACA | 参考/外群比较与目标成对支持结合 | 输入准备复杂；短插入PE不能证实任意远距离连接 | 具有适当参考/外群及成对文库时评估 |
| IMAP | 多初装→RACA→DESCHRAMBLER→校正的整套实例 | 历史依赖；真菌验证不能推广所有复杂真核 | 完整二代参考辅助流程的复现候选 |
| Lischer流程 / AMOScmp | 展示参考参与分区/布局及组装的机制 | 年代、平台和依赖假设不同，未验证现代大型真核适用性 | 方法学习及研发参考，不自动作为生产默认 |
| optimized-insilico | 无长分子时利用参考推断人工mate-pair约束 | 人工连接并非目标实测；第二参考同意也不能独立验证目标 | 特殊材料候选，证据类型标为reference_inferred |
| RaGOO | 旧论文和旧项目复现有价值 | 作者已停止支持并推荐RagTag | 历史兼容，不列新流程默认 |

表内是机制和适用性判断，不是本地公平benchmark得出的优劣排序。版本不明的明确未知；不得把软件名称相同、版本字符串相同视为源码相同。

## 4. 对“二代WGS＋参考”的可执行设计

1. 注册目标个体、倍性、PE/MP/linked-read真实文库、有效碱基与覆盖；参考注册accession、版本、hash、核型和质量。
2. 调查reads的k-mer、污染和GC/覆盖；初步检查参考匹配范围、唯一锚定与结构保守性。不能仅因同种/同属自动判适用。
3. 为目标选择主分支：透明参考布局、参考辅助再组装、局部分区组装或参考坐标共识。用户已有参考时，在方案中明确它的用途；不默认同时运行全部。
4. 采用RagTag等挂载时，先用适合基因组规模和杂合度的组装器产生目标contigs。该步骤依然是参考辅助全流程的一部分。必要的独立初装分支用于评估参考引入的偏差，不取代用户指定的参考分支。
5. 若要参考更早介入，先验证局部reads分配、未比对reads恢复、重复拷贝误合并及边界冗余；不能只把已有contigs按参考排序后称“参考引导局部组装”。
6. 多参考独立输出再比较，不因更多参考自动加可信等级。初装、每个参考布局、修正和最终稿分别保留。
7. 报告非N恢复、contig连续性、scaffold连续性、基因/k-mer完整度、拷贝异常及逐连接证据。参考组织后的共线图用于找差异，不能单独作自身正确性证明。

## 5. 面向后续开发的输入/输出契约（设计，未实现）

- `reference_role`：partition/layout/reassembly/scaffold/correct/patch/consensus；支持多个角色但逐步记录。
- `sequence_origin`：target_read_assembled / donor_assembly / unknown_gap。donor须进一步区分同个体、异个体、异物种。
- `join_evidence`：target_pair / target_long_read / target_hic / genetic_map / reference_inferred / multi_reference / conflict / unknown；允许并存，不能把参考模拟pairs改成target_pair。
- `input_representation`：primary、单hap、多个hap联合、collapsed或未知；与目标核型/倍性独立保存。
- `operation_changes`：reorder、reverse、split、trim、copy、fill_gap；对组件使用坐标做前后核对，不能对所有scaffolder套“非N总量恒定”。
- 必须保留未比对reads和unplaced的去向；禁止默认删除与参考不一致的目标序列，禁止将参考补入区默认为实测。
- 预期验收：真实倒位/融合、目标特有插入、参考特有插入、塌缩与重复扩张、多参考冲突、ntJoin裁切、donor来源、局部块边界。当前仅需求记录，未实现自动判定。

基础命令和原有质量要求保留在[48路线](48_二代数据与参考辅助染色体组装路线.md)；该文第7节补充不应理解成所有有参考任务必须采用历史分区流程。
