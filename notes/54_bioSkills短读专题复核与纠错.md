| 原材料中需限制或纠正的表述 | 核查后用于设计的规则 |
|---|---|
| 高于150×必然有害、加深会放大GC偏倚 | 缺乏可泛化的硬阈值；过深可增加计算和错误分支，新增数据也可能补随机低覆盖区。比较可用碱基、偏倚和软件内部取样；不自动截断至统一X |
| 长于read/insert的每个重复都不可解 | 要看拷贝相似度、唯一锚点、文库跨度和其他约束。53的穷举实验给出一个明确不可区分构造，不证明所有基因组如此 |
| 所有主流短读组装器都是纯DBG | MaSuRCA super-read/mega-read与后续重叠布局是反例；按工具实际算法选择参数 |
| 奇数k是所有DBG软件的要求 | 属于实现/模式约束；SPAdes与ABySS不能共享这条硬校验。ABySS文档有偶数k示例 |
| GenomeScope直接输出已确定倍性 | 倍性模型需指定并结合其他证据检验；拟合结果不是自动核型鉴定。参照28和46专题 |
| 组装膨大或BUSCO重复即可purge | 先区分primary/hap分相产品、倍性、真实复制、污染和未折叠等位。purge必须有深度/比对和删前删后证据 |
| OOM统一降低-m | -m含义及算法随工具不同；先查实际限额、用量、阶段和版本，不承诺降内存参数能修复 |
| auN=ΣLi²/G | 标准auN分母是组装总长ΣLi；用外部基因组长度G作分母是auNG。不能混命名 |
| 通用输出一定叫assembly_graph.gfa | 对照固定版本的实际产物；本次SPAdes为assembly_graph_with_scaffolds.gfa，解析需保留路径与gap语义 |
| 旧版信息或一例成功可直接用于当前版本 | 当前审查4.3.0，实际运行4.0.0；源码、参数、退出码与生物数据证据必须分开记录 |
