# 组装原理与证据驱动判断手册

记录：2026-11-02。这是对既有知识和本轮定向源码/文献核查的系统整理，服务于后续流程设计；没有目标物种实测。已有来源见[21基础](21_组装基础与质量判断.md)、[27测序调查](27_测序数据预判组装难度与二代补充策略.md)、[39完整性](39_组装完整性判断与缺口定位.md)、[48参考辅助](48_二代数据与参考辅助染色体组装路线.md)和[52源码补充](52_Juicer_BUSCO_Flye接口源码与排错补充.md)。下文的判断步骤是项目设计，不能当作任何软件保证。

## 1. 组装重建的对象先于软件

一个样本可能含两套或多套核染色体、性染色体、线粒体/叶绿体、共生物与污染；单细胞、肿瘤、混池和杂交材料还会改变拷贝和相位模型。先确定目标是代表性一套、primary＋alternate、两套或多套分相、染色体尺度，还是局部/细胞器产品。

同一个生物样本输出约G、2G或多于2G，都可能有不同解释。不能脱离倍性和表示方式，用长度直接判断冗余或完整；primary与alternate通常也不是对称的两个完整亲本组装。核基因组评价和细胞器回收分别验收。

## 2. 为什么数据准确、读长和跨度解决不同问题

短读的碱基准确性有利于区分变异和校正，但短分子可能无法分辨长、近乎相同的重复；长读提供更远的序列关联，仍受错误、嵌合、覆盖和重复相似度影响。HiFi不是唯一序列来源；ONT也须明确化学版本、basecaller、纠错和读长分布，不能只登记“ONT”。

普通PE两端之间的分子跨度是连接证据，不等于已测定中间全部序列。mate-pair、linked-read、Hi-C、光学图谱、遗传图谱提供的跨度及误差模型不同，不能只按测序平台统称“二代”后传给同一适配器。RNA是转录证据，不代表全基因组均匀抽样。

## 3. 组装图为什么会产生歧义

| 表示/机制 | 核心信息 | 常见歧义与开发含义 |
|---|---|---|
| de Bruijn graph | 共享k-mer将序列联系起来；有不同节点/边约定及压缩形式 | 重复可使多个位置共享路径；错误形成枝条，等位差异也可形成bubble。剪枝前不能把每个bubble都当错误 |
| overlap/string graph | 读段间重叠及方向，利用更长序列上下文 | 相似重复或等位拷贝会产生替代边；需要错误模型和分相信息，不是单纯选择最长路径 |
| repeat graph | 合并/显式表示重复路径，利用跨越和差异消歧 | 单条重复边可能对应多个基因组拷贝；图上闭环不必是完整环状染色体 |
| scaffolding graph | 既有组件间连接、顺序与方向 | 长程支持不足会出现多个解；输出最长scaffold不等于选中了真实解 |

现代软件可能组合多种表示，不能用“二代只用DBG，三代只用OLC”作绝对分类。Flye的disjointig/repeat graph和Verkko的图构建都有各自机制；入口/手册阅读不等于图算法已全审。

背景依据：[Flye原始研究](https://pubmed.ncbi.nlm.nih.gov/30936562/)、[Li与Durbin 2024综述](https://www.nature.com/articles/s41576-024-00718-w)。本轮正式综述页面只取得摘要/图题/参考，算法扩展说明还复用既有笔记及公开版本；不声称全文和补充均已通读。

## 4. 数据够不够：至少回答五个问题

1. **有多少有效目标数据？** 分平台/文库记原始量、通过过滤量、目标核数据估计、重复分子和个体来源；不知道污染/细胞器比例时保留不确定性。
2. **分母是多少？** G取一套核基因组大小，注明估计方法/范围。不能用已经塌缩的assembly长度算出虚高覆盖，又据此证明无需补测。
3. **区域均匀吗？** 平均覆盖可能掩盖GC偏倚、性染色体、低覆盖片段和组装错误；多重比对的深度也不能当作唯一位置覆盖。
4. **能跨过困难结构吗？** 看长尾和可用跨度，而非只看平均长度或N50；关键重复附近是否有可靠锚点和独立支持分子。
5. **模型和目标匹配吗？** 多倍体、混池、结构杂合、跨个体Hi-C分别判断；同一D/G不能保证相同的每hap覆盖及相位信息。

平均覆盖`C=D/G`。只有在随机、均匀、独立抽样等理想条件下，某位点零覆盖概率才近似`exp(-C)`；真实文库的偏倚可能使高平均覆盖下仍有缺口，不能靠此公式证明全基因组无缺失。

一个用于解释读长价值的简化量：对长度R的同一重复和两端各a的可靠锚定需求，均匀采样下该位置的期望完整跨越分子数可近似为`Σ max(0, L_i-R-2a)/G`。它不是正式成功率估计器；锚定唯一性、错误、重复变异、倍性和局部偏倚会改变结果。重复内部的可靠差异也可能帮助组装，不要求所有重复都由单条read整段跨越。

HiFi路线执行用户规定的有效≥50×；其他路线按其模型和目的评估，不机械套同一阈值。下采样对照只能估计当前工具/数据的收益趋势；不能因一次N50饱和就断定测序充分。

## 5. 测序前后怎样判断组装难度

调查阶段看G及拟合可信度、杂合度、倍性线索、k-mer拷贝谱、GC/覆盖偏倚、短读能跨越的尺度和长读长尾。重复比例是线索：少量很长且高度相似的重复，也可能比大量短且分化的重复更难。

试装后把困难定位到图分支、断点、覆盖和重复注释，检查是否缺少唯一锚点/跨越分子。RepeatMasker注释比例描述已识别重复，不能完整量化全部组装歧义；组装已塌缩时，该比例本身也可能低估真实情况。

| 观察 | 候选解释 | 下一步区分证据 |
|---|---|---|
| 深度低且断裂 | 数据不足、GC偏倚、真缺失、比对参考差异 | 原始k-mer、GC/深度、比对质量、邻域及独立数据 |
| 深度高、拷贝k-mer缺失 | 重复/等位塌缩、细胞器/污染混入 | 图、唯一锚点、k-mer拷贝、分类和reads跨度 |
| 总长大、很多相似contig | 等位未折叠、真复制、多倍体、污染 | 产品角色/倍性、深度分布、相位与分类；不能直接purge |
| 高杂合峰且图复杂 | 等位差异、多倍体、混个体或污染 | 样本身份、Smudgeplot适用模型、等位比例、分类和家系证据 |
| contig长但Hi-C跨染色体异常 | 错连、真实SV、跨个体不匹配、多重比对 | 目标个体局部read、独立图谱、逐连接与同一坐标重比对 |

这些信号没有一一对应根因；报告应给出候选、检查和未知，而不是自动诊断“都是重复导致”。

## 6. 如何组合数据而不增加错误

先保证生物样本身份与坐标一致，再检查工具支持的接口。选定的混合算法可能用短读校正长读、用长读搭桥短读contig、或将不同长读用于不同图阶段；它们不等价于把FASTQ全部拼接。Flye2.9.6入口不支持直接混合不同read类型，hifiasm/Verkko也必须按固定版的专用接口传入。

同物种不同个体的序列混合增加等位复杂度；Hi-C来自另一只个体时不能自动当成目标个体相位真值。不同平台证据若同源于一个参考或一个既有组装，也不能算作两份独立结构验证。

先保留S0基线，再做新增证据分支；比较恢复的序列/结构、引入的冲突、资源成本和无法确认范围。数据更多可能提高信息，也可能增加错误、污染、偏倚和资源负担；是否贡献由对照确定。

## 7. 校正、去冗余和挂载分别改变什么

- **polish**改变碱基/小变异，部分工具还会改结构；每轮核查改动及QV/基因/同源拷贝，避免将真实等位差异抹平。不能为所有高准确组装默认重复多轮。
- **purge**改变保留的序列/拷贝；必须有目标表示和证据，保留移出序列、区间和未purge基线。BUSCO的D下降不代表真实拷贝没丢。
- **scaffold**主要改变组件归组、顺序、方向及gap；一些流程包含切断或填补，必须拆开记录。AGP与FASTA能一致重建，只证明文件交接正确，不证明生物结构正确。
- **reference assistance**利用已有结构先验；对该参考的漂亮共线图是预期结果，不是独立验证。不同来源补洞的碱基必须可追溯。

## 8. 指标冲突时，按问题而不是按分数裁决

| 情景 | 应如何解释和行动 |
|---|---|
| N50上升，BUSCO/QV近似不变 | 可能只是重排，也可能错连；核查结构/逐连接，不直接标“组装提高” |
| BUSCO高，k-mer恢复率低 | 保守基因区可能较全，重复/特异序列仍缺失；也检查reads模型与hap评价口径 |
| purge后D下降，但可靠k-mer与非N长度显著丢失 | 核查真复制/等位拷贝是否被删；没有生物证据不能仅凭D下降选择该版本 |
| QV高，没有N，但长度偏小 | 可能塌缩/丢序列；检查预期G、拷贝谱、末端、复杂重复和独立结构证据 |
| 两个hap的BUSCO均好 | 仍可能存在相位切换和染色体父母来源混合；必须另评相位和表示完整度 |
| 注释基因数比参考多很多 | 可能真实扩张，也可能异构体、碎模型、TE、冗余/污染；不能按基因数高低选择最终注释 |

## 9. 三个可直接转成流程策略的情景

**只有100×二代WGS，有近缘参考：**确认有效核覆盖与文库，先调查并独立初装；分别评价S0和参考排序Sref；保留unplaced和N/gap来源。可形成参考辅助染色体尺度结果，但未知重复与连接仍需报告，不从100×直接推导可达高标准。

**HiFi 45×，ONT总量很大：**按本项目HiFi门槛仍标未达；另报ONT质量/纠错/长尾和目标核有效量。若工具支持联合可开探索分支，不能把ONT相加后说“HiFi已到50×”。是否联合改善由分支评价决定。

**两个hap已装好，只有异个体Hi-C：**保留初装，不将两个hap合并再机械purge；分别测试挂载贡献、冲突和未知，核型/性别差异单列。未验证的相位和远距连接不能因染色体数吻合而通过。

## 10. 学习结论如何进入开发

每个判断保存问题、适用条件、观测证据、替代解释、下一步检查、可能操作、版本范围、来源和执行状态。通用原理可以复用；版本依赖的参数、错误修复和数据库行为须按所选构建核查。标准文献的最低要求、本项目高目标和运行起点分别存储，防止程序把其中一种误当另一种。
