## 1. 先纠正路线范围

**全基因组组装不要求必须有 HiFi 或 ONT。** 二代 WGS 可以从头组装；染色体尺度组织还可来自 Hi-C、遗传连锁图谱、光学图谱或参考同源关系。Hi-C 通常也用二代平台测序，但它是专门建库的空间连接证据，普通 WGS PE 数据不能替代。普通 PE、长插入 mate-pair、linked-read 也不是同一种文库。

必须分开判定：碱基来自哪里、contig 是否正确、染色体连接来自什么证据、缺口是否仍存在。染色体级 scaffold 可以含大量 N，不能称为完整染色体序列或 T2T。

此前用户规定的有效 HiFi D/G≥50×继续用于 **HiFi 路线**；新增二代路线不因没有 HiFi 自动失败。二代的有效覆盖、GC 均匀性、重复率、杂合度、倍性、插入片段跨度和区域覆盖分别评估。没有适用于所有物种的“100×二代保证染色体级”规则；同样不能用100×二代抵扣既定HiFi路线的50×门槛。

## 2. 方法选择矩阵

| 现有数据 | 可采用的方法/工具 | 合理交付与主要限制 |
|---|---|---|
| 普通二代 WGS，无近缘参考和长程证据 | ABySS、MaSuRCA；杂合二倍体考察 Platanus-allee；小而简单基因组另考虑 SPAdes | 从头 contig/scaffold 草图；复杂真核不能仅凭数据量承诺染色体级 |
| 二代 WGS＋高质量近缘参考 | 根据目标和输入比较参考引导局部组装、参考辅助再组装及独立初装后 RagTag 等挂载；多路线及适用条件见[59](59_参考辅助组装方法体系与工具选择.md) | 产品和参考依赖随路线变化；参考推断的连接须标明，不能等同独立结构验证 |
| 二代 WGS＋参考＋适用的成对文库 | RACA；AlignGraph 作初装延伸/连接的研究候选 | 可利用目标 reads 约束部分连接；普通短插入 PE 无法验证任意远距离连接 |
| 二代 WGS＋Hi-C | 初装→适配的 Hi-C 比对/过滤→YaHS、3D-DNA 或 GreenHill 候选→人工审图 | 有样本长程结构支持；初装过碎/重复过多仍可能挂不上或挂错 |
| 二代 WGS＋Hi-C＋参考 | 固定同一初装，独立运行 Hi-C 和参考挂载，比较连接；参考辅助定位/命名 | 按样本结构证据裁决冲突；不能强制照参考染色体数或顺序 |
| 二代 WGS＋遗传连锁图谱/光学图谱 | ALLMAPS 整合合适的标记图谱；光学图谱使用对应平台流程 | 连锁图谱低重组区分辨率有限；光学图谱不能填出缺失碱基 |
| 只有 reads＋参考，直接比对和变异替换 | BWA/BWA-MEM2→变异检测→明确策略的 consensus | 参考坐标下的样本共识；没有检出的区域/变异不能假定与参考一致，不能当作独立从头组装 |

这些工具是条件分支，不是必须全部串联安装的流水线。历史 ALLPATHS-LG、SOAPdenovo 等说明二代曾广泛用于组装，不因其论文经典就默认作为新项目首选。大、高重复、高杂合或多倍体基因组尤其需要先试装再决定。

## 3. 参考到底怎么使用

### 3.1 一个可比较的调查分支：独立初装，再参考辅助排序

1. 确认是全基因组 DNA WGS，而非 RNA、外显子捕获、RAD/GBS；登记物种、个体、性别/倍性和所有文库。
2. fastp/SeqKit 检查质量、配对、有效量和污染线索；KMC/FastK＋GenomeScope2 做多 k 调查，必要时结合 Smudgeplot 和独立基因组大小证据。高覆盖不代表每个区域有覆盖。
3. 按规模/杂合度选择二代组装器，保留未用参考的初装 S0、图、日志和全部序列。hifiasm 不能接受普通 Illumina PE 代替 HiFi。
4. 比较候选参考的分类身份、来源、组装质量、核型、倍性、可比对比例/一致性和共线性；同种优先考虑，但同种也可能有真实重排。不设通用“同属即可”或固定分歧年限规则。
5. RagTag scaffold 生成 Sref，保存 FASTA、AGP、confidence、PAF、未定位 contig 和版本/参数。
6. 有第二个合适参考时，对相同 S0 独立生成另一 Sref；记录稳定连接和参考敏感连接。不同参考一致仍不等于目标样本真值。
7. 有 Hi-C/连锁图谱时，从 S0 建独立分支 Shic/Smap，对逐连接核查，人工审阅后定稿。

RagTag v2.1.0 文档支持的最小调用模板（未执行；运行前核对锁定版 CLI）：

```bash
ragtag.py scaffold -t 16 -u -o results/reference_A reference_A.fa draft_S0.fa
ragtag.py scaffold -t 16 -u -o results/reference_B reference_B.fa draft_S0.fa
```

基准模板不拼接 unplaced 为 chr0；chr0 不是生物学染色体。不默认打开覆盖旧结果或按参考推断 gap 长度的选项。默认插入的100个 N是占位，不是实测 gap 大小；`-r` 推断的间距也不是目标样本真实测量。多参考 merge 要求所有 AGP 引用相同组件和坐标体系；不能直接合并经过不同切断/去冗余后的 AGP。

依据：[scaffold 手册](https://github.com/malonge/RagTag/wiki/scaffold)、[merge 手册](https://github.com/malonge/RagTag/wiki/merge)。

### 3.2 排序、切断、补洞、直接共识要分开

| 操作 | 序列来源/变化 | 流程要求 |
|---|---|---|
| RagTag scaffold | 对 query 排序定向并加 N；不从参考复制碱基 | 非 N 序列应可追溯到 S0；保留未挂载序列 |
| RagTag correct | 在疑似错误处切断 query；支持用同基因型 reads 检查 | 参考不一致可能是真实 SV，不能自动全部切断；需记录断点与证据 |
| RagTag patch | 用另一套 assembly 的片段连接/填洞 target | 如果 donor 是别的个体/物种，会有非目标序列来源；默认不作为本项目补洞方案 |
| MaSuRCA chromosome_scaffolder | 参考辅助排序，可结合长 reads 检查切断，可选参考填补 | 长 reads 验错模式不是普通 PE 功能；手册无长读时要求 `-nb`；不默认启用 `-M` 参考填补 |
| 变异替换得到 consensus | 很多坐标和未修改碱基继承参考 | 明确低/无覆盖 mask、杂合位点表示、SV/新序列限制；交付名称标明 reference-coordinate consensus |

依据：[correct](https://github.com/malonge/RagTag/wiki/correct)、[patch](https://github.com/malonge/RagTag/wiki/patch)、[MaSuRCA 官方 README](https://github.com/alekseyzimin/masurca)。上述处理风险是根据各工具操作机制推导的项目规则。

## 5. 没有长读时，如何判断结果可信

以下是本项目验收设计，需用实际数据校准；缺证据一律记录未知，不能按参考替代目标真值。

| 维度 | 要检查什么 | 不能得出的结论 |
|---|---|---|
| reads与序列一致性 | 双端比对覆盖/方向/插入分布、异常深度、软剪切；污染及GC偏倚 | 高mapping率不能证明远距离连接或重复拷贝正确；同一批组装reads回贴非独立验证 |
| 碱基与拷贝完整度 | 合适可信k-mer集合的Merqury QV、恢复率、spectra-cn；同源拷贝与重复塌缩 | QV高不等于结构正确；同源/多倍体组装需匹配表示模型；同数据自评需标记依赖 |
| 基因完整度 | BUSCO固定软件、谱系库版本/日期、模式/后端，比较S0/Sref | BUSCO高不说明间隔区/重复完整，不能证明染色体顺序；重复BUSCO不等于必须purge |
| contig与scaffold | 分开报告contig N50、scaffold N50、非N总长、N量、gap数及unplaced非N比例 | 排序后N50上升不等于新增真实序列；参考推断gap不能计入恢复碱基 |
| 逐连接结构证据 | AGP每个连接标注reference-only/Hi-C/遗传图谱/目标跨度支持/冲突/未知 | 同一参考的共线图不能独立验证由该参考排序得到的连接 |
| 核型与真实SV | 多参考敏感性、核型/标记证据、Hi-C局部异常、保留跨染色体比对 | 不能因不同于参考就判错误，也不能从软件输出scaffold数量反推目标染色体数 |
| 未解区 | 重复拷贝、性染色体、rDNA、着丝粒/端粒、目标特有未定位序列 | 无N也可能有塌缩和丢失；不能据此宣称T2T |

普通PE只有实际分子跨度内的支持力。例如500 bp左右文库不能验证跨100 kb未知gap的两端相邻；没有跨越reads也可能是跨度不足，不能直接判错。100×仍无法用覆盖深度消除长且近乎相同的重复所造成的组装歧义。参考越接近且质量越好通常更适合排序，但相似度本身没有消除偏差的保证。

若目标是新物种高标准参考，二代＋参考可作为阶段性成果；是否补Hi-C、连锁图谱或长读，取决于未验证的连接和未恢复序列，而不是看scaffold N50是否已很大。没有独立长程证据时，明确称“reference-assisted chromosome-scale scaffolds，结构尚未独立验证”，不可自动宣称达到此前高标准验收。

## 7. 2026-11-02 对“参考参与组装本身”的补充纠正

用户明确提供参考时，不能只回答独立初装后参考排序。需要区分以下三种参考介入位置；选用从头组装组件并不等于整个流程没有利用参考。

1. **参考引导的局部从头组装**：先将目标 PE reads 比对到近缘参考，划分连续覆盖块及重叠 superblocks，在块内从头组装并合并；同时组装、整合未比对 reads，避免丢失参考缺失或分化区。Lischer & Shimizu (2017), *Reference-guided de novo assembly approach improves genome reconstruction for related species*, BMC Bioinformatics 18:474, DOI 10.1186/s12859-017-1911-6，明确提供这种路线。作者代码入口见论文资料可用性声明： https://bitbucket.org/HeidiLischer/refguideddenovoassembly_pipelines/ 。本次读取论文方法及可用性部分；没有运行原脚本，原代码当前可访问性、版本及现代依赖兼容性未核实。该历史实现是方法依据，不直接包装为当前可用生产流程。
2. **参考辅助再组装/延伸**：AlignGraph 接受目标 paired-end reads、初装 contigs/scaffolds 和近缘参考；利用比对构建 PE multipositional de Bruijn graph，再延伸/连接。不是只做参考排序。原版官方说明 https://github.com/baoe/AlignGraph ，论文 https://pmc.ncbi.nlm.nih.gov/articles/PMC4058956/ 。本次复核 README 输入和算法摘要，未安装/运行；AlignGraph2 的长读用途不得套用到只有二代的场景。
3. **参考辅助挂载**：RagTag scaffold 接受参考 FASTA 和初装 FASTA，排序、定向并加 N；不接受原始 FASTQ 直接完成 reads 组装，也不延伸 query 的实际碱基。依据 https://github.com/malonge/RagTag/wiki/scaffold （页面标注 v2.1.0）。

按参考坐标变异替换生成 consensus 也是可选产品，但应单独标明，不等同于恢复目标样本全部新序列。上述路线都需要保留未比对/未定位序列；无覆盖区域不能静默复制参考后作为目标实测序列。是否使用参考引导路线，应先评估参考与目标的亲缘、质量、共线性及目标 reads 覆盖，不能默认必然优于参考独立初装。软件开发增加 `reference_guided_local_assembly` 和 `reference_assisted_reassembly` 路由设计，当前未实现；原有独立初装可作为偏差比较分支，不应代替用户要求的参考参与路线。
