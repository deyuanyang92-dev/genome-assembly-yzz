# Hi-C订购量：按HapHiC深度实验修正生产判断

日期2026-11-03。用户指出，仅给EBP总量基线和“试测后再说”，未把已有测评/方法论文转为生产依据。本次新增取得并读取HapHiC官方Supplementary Data 1的Sheet 3及14；保存原始xlsx、完整两表TSV、HapHiC行摘要和下载哈希。证据为论文数据复核，不是本地重跑或新物种验证。

## 原始证据

- [HapHiC论文](https://doi.org/10.1038/s41477-024-01755-3)，[本地新取回数据](hic_depth_review_2026-11-03/provenance.json)。有效深度从过滤后Hi-C中抽样；原PDF Table 3中全部数据为110443496对、22324670268碱基、10.9×，1×档为10161564对、2054060928碱基。由表内数据反算分母约2.05Gb，是模拟模板的总跨度；不能改为物种基本单倍组大小。原读对约2×101bp，转成PE150订单时应先选择按碱基还是按读对迁移证据，不能默认二者等价。
- 同一深度实验的Sheet 3评价归组，Sheet 14评价排序/方向；后者syntenic百分比按论文真值/分类规则解释，不等同碱基QV或所有连接准确率。两表分类/分母并非每一列完全相同，不能随意相减。

原始精度见[提取摘要](hic_depth_review_2026-11-03/haphic_depth_summary.tsv)。本模拟基于作者修订的苜蓿四倍体模板和真实Hi-C；低深度另降低链接救回阈值，不能将结果写成任意样本默认参数保证。本文没有核实深度实验专用输入的确切N50配置，因此不为此表补填未经确认的N50，也不依据本表生成通用N50—深度阈值。

结论：在这个实验中挂载率接近100%时，排序/方向质量仍可明显恶化。0.02×或0.05×“仍能挂载”不构成生产最低量；1×接近全部数据的某些指标也不等于该样本已满足用户全部质量目标。增加深度不能自动消除初装错误或读对定位歧义。

## 另一篇benchmark的单位必须单独处理

[Sur等2026](https://doi.org/10.1186/s13059-026-03978-3)的下采样实验以100kb参考切片输入为基线，报告50 aligned reads/kb以下开始出现性能下降，工具筛选截止2020、不包含HapHiC/YaHS。其本地固定`main/alignment/sample_rate.py`实际公式为`(flagstat mapped/2)/(FASTA bp/1000)`；mapped记录不是严格的双端均有效、去重分子数。必须保留作者文字与实现的区别。

仅按该实现，1Gb输入、50计数/kb对应约5000万mapped/2计数；若理想化为5000万对PE150，则相当15Gb碱基。不能写成50Gb，不能再把“10%validPairs”直接套到mapped/2的分母。正式迁移需重新以统一计数口径统计。

## 对生产咨询的约束

1. 只有HiFi时，先提供其初装和调查结果：单套大小与输入FASTA总跨度、倍性/套数、N50/N90及短片段比例、疑似塌缩/冗余/污染、唯一锚定困难程度；不需要等待Hi-C即可开展这些工作。
2. 从论文选择相近输入表示、连续性和倍性的案例，核验过滤链、深度分母、读长、下采样方式、调参及归组/排序/方向/未定位结果。不能只摘最低成功深度，不能把多篇异口径数字拼成一个保证阈值。
3. 将所需联系目标与原始订单明确关联。若采用有效读对目标N、原始读对到同定义有效读对的预计保留率f，则PE150原始Gb约为N×300/(f×10^9)。没有实测f时，可依据同建库/组织历史项目给出标注假设的多情景预算；例如10%只能作为一个情景，不是物种固定常数。若采用有效碱基深度C×输入跨度S，需声明读长迁移假设，并核查读对数量是否同时满足。
4. 交付应包含建议订购量、读对数、假设有效率范围及其来源、预期有效目标、可比论文依据、追加/重建文库条件。先给可追溯预算，再用QC修订；不能只回复“先试测”而没有预算依据，也不能因用户未报G便给任意生产数值。
5. 数据回来后固定初装，做有代表性的深度梯度和必要的随机重复，比较分组/顺序/方向稳定性、支持与冲突以及新增独立分子数。真实项目没有论文真值时，稳定不等于正确；结合长读证据和审图判断，不能用更高N50或挂载率单项决定够量。

此前将EBP>50×直接展示为订购建议应撤回；它仍是规划参考，不能改名为HapHiC过滤后必需50×，也不能未经同口径核实直接除以10%。本次未给用户样本的最终订单：其基因组/初装/建库信息尚未提供。
