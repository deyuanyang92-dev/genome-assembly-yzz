## Sanger genomeassembly 1.0.1

固定提交 `131f0ea272bb2fce9869d57f684f20f645467e34`，本地根目录 `pipelines/sanger-tol_genomeassembly/`。以下相对路径均相对此目录。

| 已读路径 | 追踪到的行为 | 对开发的影响 |
|---|---|---|
| `functions/local/assembly_stages/main.nf` | 阶段 ID 由 assembler、dataset ID、相关参数和前置 hash 拼接后 `.md5()`；有显式分支依赖 | 这是阶段标识，不是 reads 内容 SHA256，也不等于 Nextflow 全部缓存实现；细胞器分支可依赖 hifiasm，而非最终 scaffold |
| `subworkflows/local/prepare_inputs/main.nf` | GenomeScope `kcov` 四舍五入，或用 `long_read_1n_coverage` 覆盖；c 参与 oatk 和 purge 阈值推导 | 实际意义需核对数据/拟合；不能声称自动给 hifiasm 设置 `--hom-cov` |
| `conf/modules.config` | hifiasm 参数取平台标记及用户 bin/assembly arguments；核组装统计的 `MERQURYFK_MERQURYFK` 配置 `errorStrategy = "ignore" // TEMPORARY` | 必需 QV/QC 应在外层验收；整个流程成功不能替代检查该报告实际产生 |
| `functions/local/input_validation/main.nf` | 引用按 dataset ID 与 platform 匹配；同一 dataset 扩展名一致；Hi-C 接受 CRAM；HMM 伴随索引检查 | 自己的适配层应服从实际格式检查，而非只按旧注释猜格式 |
| `subworkflows/local/hifiasm_assembly/main.nf` | bin 结果按 spec.prevID 匹配后装配输入，FASTA 按 key 分组；hap 文件优先于 primary/alternate 回退 | 数据交接按明确 key 和角色，不能按文件出现顺序匹配 |
| `modules/sanger-tol/hifiasm/main.nf` | CRAM 用 samtools 转双端，UL 用输入分支；很多生物输出 optional；stub 可 touch 文件 | 文件出现不等于真实组装完成；固定版本兼容后再封装 |
| `subworkflows/local/purging/main.nf` | 使用前置 assembly ID 连接输入，保留去除 haplotigs 等输出 | purge 是有证据的序列取舍，不能只保留最后 FASTA |
| `modules/nf-core/yahs/main.nf` | FASTA/FAI/Hi-C 比对/可选 AGP 交接，最终 FASTA 和 AGP optional，bin/log 输出 | 对最终交付另设必需产物和一致性检查 |

### Trio 亲本标签的静态追踪风险

调用者 `hifiasm_assembly/main.nf` 给 trio channel 的顺序是 `[spec, maternal.yak, paternal.yak]`。被调用模块的对应 tuple 命名为 `[meta3, paternal_kmer_dump, maternal_kmer_dump]`，再构造 `-1 paternal_kmer_dump -2 maternal_kmer_dump`。因此按位置传参的静态追踪，**当前调用链的 -1 实际得到 maternal，-2 得到 paternal，和模块变量名所暗示的身份相反**。

这是已定位的命名/顺序风险，尚无本地 trio 集成数据证明最终文件生物学归属发生什么影响。不能据此宣布组装序列错误，也不能未经验证重命名输出 hap1 为父本。实际使用前要查看运行命令和输入 yak 身份，再用已知亲本标记验证输出角色。此处没有修改上游源码。

## hifiasm 与 Merqury 的补读

- `pipelines/lh3_hifiasm/README.md`：Hi-C 模式的染色体间父母组合可能混合，hifiasm 本身不做 scaffolding；因此 hap1/hap2 不自动等于全基因组父本/母本。固定 SHA 见源码清单。
- `pipelines/marbl_merqury/eval/qv.sh`：由 assembly-only k-mer 比例及 k 推导每碱基错误概率，再转 Phred QV；`best_k.sh` 给出的规模/碰撞公式输出还需确定整数选择；README 的数据库和版本要求需跟实际运行配套。
- QV 的数据覆盖、偏倚和模型前提，以及完整度与拷贝数的区别，已写入21。没有实际完成 Merqury 大数据计算，不能把阅读公式计入实测。
