## 主要恢复命令

所有命令从本学习目录运行；原科研目录只读。Snakemake及依赖清单为`snakemake_environment.txt`，固定Colora提交与输入见manifest；原始仓库为 https://github.com/LiaOb21/colora 。数据库来源及官方校验在`databases/*manifest.json`。

```bash
python scripts/run_colora.py dry-run
python scripts/run_colora.py assembly
python scripts/validate_assemblies.py
python scripts/run_colora.py scaffolding
python scripts/validate_scaffolds.py
python scripts/run_colora.py survey
python scripts/run_colora.py busco
python scripts/run_colora.py all
python scripts/snapshot_environments.py
```

不要在本目录已有运行任务时重复启动调度。命令、工作目录、退出码及时间保存在每次运行的`logs/colora_*.json`。`--rerun-incomplete`只用于隔离测试目录的中断恢复。

现有环境均位于`/tmp/yzz-learning-colora-envs`；环境会消失时可据`environment_locks/*.explicit.txt`重新创建。显式清单面向当前Linux平台；源码及YAML版本也一并保留，不把环境可安装当作跨平台验证。

## 已解决的运行问题

1. Snakemake默认缓存路径只读：本轮使用`XDG_CACHE_HOME=/tmp/yzz-learning-cache`，未改全局配置。
2. 教程BUSCO数据库旧URL 404：按官方file_versions选择2026-05-22的同名odb12，官方MD5通过并保留索引。
3. BUSCO即使有本地lineage也尝试联网查版本：已停止重试命令，改本地配置`--offline`，保留首次日志和停止原因。
4. 中断后锁遗留：只读确认剩余Snakemake为`--conda-create-envs-only --nolock`，没有分析任务后才执行`--unlock`；恢复过程不删除科研数据。

## 解释边界

本例为作者明确说明没有生物学验证用途的不同菌株子集；回贴主要是核染色体I、XI及线粒体。S288C参考和蛋白用于独立比对与证据投射，不是SPSC01严格真值。G、倍性、相位正确率、QV、结构正确率、真实多毛类注释准确率尚不能由此证明。FCS-GX在本测试配置关闭，因此没有污染合格结论。
