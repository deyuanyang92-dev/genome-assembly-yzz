# 测序数据预判组装难度与补充二代的决策

2026-11-01。当前没有用户 reads，以下是可执行的调查方案与解释规则，不是某个物种的实测结论。软件与现成脚本见[28](28_基因组调查源码与脚本使用说明.md)，开发缺口见[29](29_基因组调查开发待办.md)。

## 1. 先区分能够回答的问题

已有 reads 可以评估数据质量、基因组大小、覆盖、杂合/倍性信号，以及重复导致组装困难的风险。它不能完整预测取样、DNA 提取、建库成功率；需要 DNA 完整性、纯度、组织/保存条件和试建库记录。也不能从一个重复比例或杂合率直接保证 contig N50、染色体完整度或 T2T。

分两阶段：**组装前调查提出风险；初步组装用图、覆盖和断点验证原因。** “重复很多”是描述，“长而高度相同的重复缺少可区分路径”才是待验证的组装机制。高杂合、多倍体、污染、平台遗漏和计算资源不足也会导致碎片化。

## 2. 输入与覆盖口径

登记 specimen ID、物种/性别、是否混样、平台和化学版本、HiFi CCS/过滤记录、所有文件校验值、是否同一个体、是否有亲本、预计倍性。不得把 subreads/CLR 当 HiFi；FASTQ 没有保留 BAM 的全部 read-quality 标签，缺失信息应标记未知。

分别报告原始碱基、质控后碱基、能够归属目标核基因组的有效碱基及其估算依据。SeqKit 统计的是文件碱基；没有污染/细胞器评估时，不能直接宣称它们全部是有效核数据。读长过滤也会改变覆盖与重复跨越能力，不能为提高 N50 任意丢短 reads。

本项目硬要求：`C_HiFi = D_HiFi,有效核 / G_单套核 ≥ 50×`。这里二倍体分母为一套核基因组；50×总覆盖约为每条同源单倍型25×。多倍体须明确单套、基本组和同源/亚基因组的口径，不能沿用二倍体峰解释。

若调查得到可信范围 `[G低,G高]`，则覆盖范围为 `[D/G高,D/G低]`；按保守端判断50×。缺口 `max(0,50×G高−D)`。这只是依据候选估计的规划范围，不自动是统计置信区间。若模型失配或目标核有效数据量不明，结论为待确认，不能判定达标。

示例：G约800 Mb，目标有效HiFi至少40 Gb。另有有效二代80 Gb则二代为100×，不是HiFi150×。PE数据量按R1与R2碱基相加；未质控的订购产量需另留损耗余量。

## 3. 调查步骤、判断和后续动作

| 问题 | 工具与必须保留的证据 | 怎样解释、怎样处理 |
|---|---|---|
| 数据量和读长是否够 | SeqKit stats；HiFi平台质量报告；读长分布、N50、长读尾部及各批次统计 | 平均50×不能保证所有区域50×；短读尾、低质量批次需分别核查。短reads占比和最长read不能替代分布 |
| G大概多少 | canonical KMC直方图→GenomeScope2；至少比较k=21/31起步及合理倍性模型；保留线性/对数图、拟合残差和JSON | 比较估计、拟合与高频尾；分峰不清、拟合很差、k变化导致G大变时不报精确单值。更大k须按G/错误和计算量选择 |
| 独立算法是否支持G | LRGE基于长read重叠；有条件用流式细胞术/直接C-value旁证，GoaT区分实测与推测 | LRGE默认细菌规模抽样不能直接搬到大型真核；不同方法一致增加信心，不能把同批reads的两个算法称独立实验 |
| 杂合和倍性是否复杂 | GenomeScope2估计；FastK→Smudgeplot；物种核型/生殖史/样本信息 | 杂合峰、重复与多倍体可混淆；低杂合会让Smudgeplot缺乏信息；不能仅凭图判定真实倍性。高杂合增加分型挑战，也可提供分型标记 |
| 重复是否是主因 | 调查阶段看k-mer重复模型和高频尾；初装后结合GFA、重复注释、自比对、contig末端和原始read跨越 | 模型重复量不是完整的长重复长度/相似度分布，也不能定位全部难区。必须核查长度、相似度、排列、区分位点和路径支持 |
| 污染/细胞器是否干扰 | 初步分类筛查；初装后GC–深度–分类/BlobToolKit或FCS等多证据；保留数据库版本 | 高频峰不全是重复；可能为线粒体/叶绿体、微生物或真实多拷贝核序列。不能只按GC或深度自动删除 |
| 数据是否局部缺失 | 初装后用HiFi深度、缺失可靠k-mer、未组装reads和其他平台数据检查 | reads从未覆盖的区域无法仅凭这些reads可靠量化；一个平台平均深度高也可能有系统性遗漏 |
| 计算资源是否足够 | 小规模试运行的日志、CPU/峰值内存/临时盘；数据量、唯一k-mer规模和图复杂度 | 资源失败不等于生物学上不能组装；抽样运行也不能保证线性外推，正式运行保留资源监测 |

GenomeScope当前固定源码的 `kcov/lambda` 是每条同源拷贝的k-mer覆盖参数；典型二倍体杂合峰约λ、纯合峰约2λ。它不是直接的总碱基D/G，不能照错误模板把纯合峰值塞入λ。短read的k-mer覆盖还受 `(L−k+1)/L`、错误及过滤影响。

GenomeScope区间来自模型及系数误差，并未囊括所有污染、倍性错误、平台偏差与高频截断的不确定性。KMC计数器上限 `-cs` 饱和与 `-cx` 排除不是同一回事；高深度重复尾被压缩或截断会影响G和重复估计。保存计数配置，做上限敏感性检查，不能因为软件拟合成功就认为G准确。

## 4. 如何验证“重复造成组装困难”

先满足覆盖、read质量与资源检查，再核查：断点是否富集在长/高相似重复；图上是否有候选多路径及拷贝深度支持；原始reads是否能从一侧唯一锚点连接到另一侧，或利用重复间变异逐步区分路径；与杂合分支、污染和真实结构变异相比哪个解释更符合证据。

例如多数reads15–20 kb、候选重复80 kb且高度相同，缺少路径区分信息时风险很高；同长度reads加量不必然解决。反过来，重复有足够差异时可用重叠区分，不要求每个重复一定由一条read完整跨越。初装缺失的重复不会被装配后注释完整统计，因此低注释比例不能排除重复困难。详见[21节7](21_组装基础与质量判断.md)。

结论必须落实到动作：覆盖不足→按保守G补足HiFi；分型复杂→选择相符组装模式/增加亲本或Hi-C证据；长重复缺信息→评估超长ONT；染色体连接不足→Hi-C及人工校正；污染→分类核实并按需重组装。Hi-C不能补出没有组装出的重复碱基。

## 5. 增加100×普通二代WGS是否可行

**可以，但不是HiFi调查或hifiasm组装的强制前置条件。** EBP 2026 v4 的HiFi方案不强制普通短read WGS；该文件仍讨论亲本短reads、必要时的polishing，且Hi-C本身通常通过短read平台测序。因此“EBP完全不再测二代”并不准确。EBP最低推荐与本项目用户要求50×也不能混为一谈。

| 数据方案 | 实际用途 | 不能由此保证 |
|---|---|---|
| 有效HiFi≥50× | HiFi k-mer调查、hifiasm初装、图/覆盖/完整性评价；可用HiFi k-mer评估但须注明同源数据依赖 | 不保证染色体级、全局分型或T2T |
| 有效HiFi≥50×＋同个体普通二代WGS约100× | 另外独立建二代k-mer库；对照G/杂合/重复模型；后续以Merqury等评估HiFi组装的QV、缺失与拷贝数信号；候选局部错误可交叉核查 | 不替代HiFi50×，不直接跨越长重复，不是100×就必定准确完整，不自动要求polish |

这里100×是单套G分母的总覆盖；二倍体约每条同源单倍型50×。数据深度可行，是否值得补测取决于预算、已有数据和缺失证据；本轮不把它新增为强制100×门槛。先确保普通WGS与HiFi来自同一个体、质量合格、双端对应；记录接头、质量、PCR/重复、GC覆盖偏差。调查用k-mer前避免不加区分地把自然高深度重复当PCR重复删除。

**分别调查两种数据，不直接混合拟合，不将两个G机械平均。** 不一致时逐项检查同个体/同物种、混样、污染与细胞器、GC偏倚/平台遗漏、k值、计数饱和和直方图截断、错误过滤、倍性及模型拟合。必要时用初装和直接C-value实验交叉核实。Illumina可靠k-mer也可能因覆盖偏差而缺失；独立平台不等于绝对真值。

普通短reads不能替代Hi-C的长程接触信息；Hi-C也不能当作覆盖均匀的100×普通WGS直接解释。其他个体二代数据可作辅助群体背景，但个体变异会影响组装评价/修正，不能按同个体校正证据使用。

HiFi组装不默认进行多轮二代polishing。先判断是否有可重复、可可靠定位的错误；若修改，需控制重复区错比对与单倍型混合，使用完整组装材料作竞争比对，并在同一评价口径下比较修改前后QV、完整性和分型。总体QV上升不能掩盖真实等位基因被改掉。

## 6. 每个样本应交付什么

1. 输入清单、样本关系与数据质控表；HiFi和二代数据分开。
2. G候选范围、倍性假设、各k拟合图、配置和失败模型；有二代时交付跨平台一致性解释。
3. 有效HiFi覆盖范围、是否满足50×、缺口及估计的不确定性。
4. 风险证据表：重复/杂合/倍性/污染/遗漏/资源，分别写支持、反证、未知和下一步操作，不产生未经验证的“难度分数”。
5. hifiasm初装后更新上述判断，交付contig/NG50、k-mer完整性/QV、BUSCO、拷贝数、污染和图；达到染色体级还需挂载与结构校正，验收遵循[23](23_EBP2026规范与本项目对标要求.md)。
