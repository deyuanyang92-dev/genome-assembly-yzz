# 公开环节动物数据再利用：核心基因与机器学习可行性

2026-11-01；对应用户新增思路。结论：可开展，但应先盘点已有组装与注释，再决定补组装/补注释；核心基因发现与注释模型训练是不同任务。此文是可行性调研与QS016开发规格，不是已完成跨数据库资产普查或模型训练。暂按“跨主要环节动物类群稳定保留的同源基因＋其中可用的单拷贝标记”理解核心基因，待用户进一步明确；同时保留特有基因/功能和训练两个分支。

## 先修正数据前提

[DToL数据说明](https://www.darwintreeoflife.org/data/)和[FAQ](https://www.darwintreeoflife.org/faqs/)明确同时发布原始数据、组装、Genome Notes与Ensembl注释；注释还可能先在FTP出现。不能因为ENA/GenBank某页无GFF，就判断“EBP没有组装/没有注释”。EBP包括多个项目，项目门户和INSDC/Ensembl需交叉查询。

| 已核实的资产状态 | 本项目处理 | 不能下的结论 |
|---|---|---|
| 仅原始DNA reads，未检到公开组装 | 登记时间/搜索范围；核实后进入调查、组装、去污染、QC，再注释 | 未检到不等于不存在；不可直接在reads上生成可靠全基因组坐标注释 |
| 有组装，未检到匹配注释 | 优先候选：找RNA/蛋白，补注释并与其他来源核对 | GenBank无GFF不等于Ensembl/作者补充资料无GFF |
| 有组装和注释 | 建立原版对照；统一重注释仅在比较公平或纠错目的下开展 | 原版有BUSCO不等于全部结构正确，也不等于必须重组装 |
| 有多个组装、hap或多个注释集 | 按物种、样本、assembly accession.version、hap与gene-set版本去重/分层 | 不把同一物种两个hap当两种物种；不拼接不同FASTA版本与GFF |

“公开无可用注释”的比例需要逐条资产清单才能估计。本轮没有获取完整环节动物清单，不提供虚构总数。若需重组装，沿用目标个体有效HiFi≥50×的本项目要求，低于门槛可做探索对照但不能标成本项目达标新组装；现有公开组装的可用性按实际质量和研究角色独立评估，RNA没有50×硬门槛。

## 已有人做过什么：直接相关先例

- [AnnelidaDB，NAR，2026-10-31，DOI 10.1093/nar/gkag1087](https://academic.oup.com/nar/advance-article/doi/10.1093/nar/gkag1087/9005756)：论文报告覆盖152个有核基因组的物种；保留来源注释，有公开RNA时补做RNA/同源/从头证据整合，并另外用ANNEVO注释。它与“收集公开环节动物组装并补注释”的想法显著重叠。数字是该论文快照，不是我们独立盘点出的当前EBP基因组数，也不代表152个高质量训练真值集。
- [Annelid Comparative Genomics…，MBE 2024，DOI 10.1093/molbev/msae172](https://pmc.ncbi.nlm.nih.gov/articles/PMC11371463/)：对23种环节动物补做基因预测，分析直系同源与染色体演化；[Dryad](https://doi.org/10.5061/dryad.brv15dvhv)公开相应GTF、CDS和蛋白。可以作复现/对照入口，不能直接作为所有基因正确的监督标签。
- [AnnelidaDB使用指南](https://www.annelidadb.com/user-guide/)区分来源模型和ANNEVO模型，说明记录可用性不一；下载时需保持对应关系。其About页本轮仅得到界面外壳，论文所称源码链接未能定位，不能宣称已经收集/审读其全套源码。

因此初步判断：单纯“再次批量注释”与既有研究重叠较多。更具体的可检验问题包括：统一证据标准后核心基因是否稳定；哪些所谓基因缺失实为漏注释；对新科/新目能否改善预测。这是研究设计推论，不是已证明存在创新或可发表的结论。

## 核心基因必须定义清楚

| 目标 | 操作定义建议 | 额外证据 |
|---|---|---|
| 保守核心家族 | 在预先定义的高质量物种集合/主要类群中广泛存在的同源家族 | 跨类群占有率、同源树、缺失补查与污染检查 |
| 单拷贝系统发育标记 | 在目标分支中有可信一对一直系同源关系的基因集合 | 拷贝数、旁系同源/倍性、比对质量、基因树与物种树冲突 |
| 环节动物特有候选 | 环节动物内有支持、充分外群搜寻未发现对应关系 | 敏感蛋白/HMM及基因组搜索，排除远缘检测失败/污染；缺少命中不是直接证明特有 |
| 关键功能/必需基因 | 与功能、性状或生存有因果/实验支持的基因 | 保守性或单拷贝本身不能证明必需或性状因果 |

不能要求“所有基因都严格单拷贝”，也不能用一个近缘类群占多数的物种集代表整个门。主分析可预注册软核心如≥95%占有率，并同时报告90/95/100%及按科/目平衡结果；这些是项目拟议敏感性分析阈值，不是已发表环节动物通用标准。多倍体/近期复制需分层分析。

## 核心基因分析路线及现成工具

先按主要系统分支挑选质量可比的组装/注释，保留原版与统一流程版成对比较。每gene选择有依据的代表蛋白用于家族分析；全部异构体另存，禁止把异构体当多个独立基因。数据集包含两hap时选定主分析角色，等位与hap注释保留在映射表。

用[OrthoFinder官方项目](https://github.com/OrthoFinder/)做家族、基因树、物种树及复制/直系同源判断，不只做全对全BLAST。版本间输出结构已变化，解析器应锁定版本并识别schema，不能硬编码旧目录。用[官方教程](https://orthofinder.github.io/OrthoFinder/tutorials/beginner-tutorial/)区分orthogroup与ortholog：同一orthogroup可含旁系同源，不能把其所有成员直接当一对一标记。

候选“缺失”至少按以下路径判定：

1. 在原注释、统一注释与替代模型中查找，记录证据强度和覆盖。
2. 用近缘蛋白/miniprot与家族HMM搜索目标基因组；若跨内含子需基因模型重建，HMMER直接搜蛋白阴性不能排除基因组中存在。
3. 检查候选区域是否gap/低覆盖/错拼、TE、污染或hap角色问题；结合剪接RNA和邻域/共线性。环节动物染色体重排较大，共线性缺失不是单独否定证据。
4. 有必要且有reads时局部回贴/重建；无法判断记unknown，分别记录annotation_missing、assembly_unresolved、candidate_loss等状态，不把unknown编码为确定0。

输出家族占有率/拷贝数矩阵、单拷贝候选、每个缺失位点的证据和类群平衡敏感性分析。自建核心集可作质量诊断，但若核心集来自同批待评价注释，会产生循环；独立测试物种与标准BUSCO结果并列，不能据此宣布新注释全面正确。

## 机器学习：可行，但训练标签是决定因素

三种任务应分别建模、分别验收：

- 基因结构预测：DNA序列→外显子、内含子、CDS/基因边界。需要匹配版本的FASTA＋高可信GTF/GFF，不是只提供原始DNA或蛋白FASTA就能训练。
- 模型置信度/整合：RNA剪接、蛋白覆盖、ORF、重复、候选间冲突等→模型排序或保留概率。可借鉴EASEL/Minos，适合先做轻量试验；没有独立标签时只能称证据评分，不能声称学到正确率。
- 家族/功能/性状：同源关系和独立功能/表型标签→预测。此类预测需要独立任务、训练目标和实验验证；核心家族发现本身未必需要机器学习。

可复用入口：[ANNEVO](https://github.com/xjtu-omics/ANNEVO)公开model_training目录，关联[Nature Methods 2026方法论文](https://www.nature.com/articles/s41592-026-03036-7)；本轮只读仓库概览/训练代码开放说明和论文检索摘要，未读完训练实现及补充资料，不能承诺任意checkpoint可以直接fine-tune。[Tiberius](https://github.com/Gaius-Augustus/Tiberius)文档明确FASTA＋GTF训练入口、每gene仅一个异构体；可用作训练工程参照，但其当前模型类群不能直接视为已有环节动物模型。

使用Ensembl/ANNEVO/其他流程的现成预测可作弱标签、候选或教师模型；不自动视为金标准。高可信标签优先参考独立短/长RNA完整结构、合适蛋白和人工复核，并保留冲突/未标注区域。已有GFF中没有标注的区域不能全部当“无基因”负样本；仅训练保守核心基因会偏向高表达保守基因，必须覆盖不同长度、内含子、表达、重复背景及非核心基因。

## 防泄漏与效果评价

按物种/科/目留出，而不是把同一个基因组的相邻窗口随机打散后宣称跨物种泛化；同一物种不同hap/组装必须在同一划分。基因组切片按染色体或区块并防止边界重叠，评估家族相似性泄漏。预训练模型可能已见目标物种，需审计训练物种表；无法排除时标注，不声称“完全未见物种”。

提供两个有意义的测试：同一物种内新区域；完全留出的科/目。若评估新家族能力，还需家族隔离或相似性控制。蛋白/RNA证据训练与评估的来源关系留档；不用待评物种自己的GFF同时当提示和真值。避免同一模型自生成伪标签后只与自身比对验证。

主指标：独立可评估区域内的核苷酸/外显子/内含子/完整CDS或转录本precision、recall、F1；融合/拆分、内部终止、短基因/长内含子/微外显子等分层结果。区分缺少真值和真实假阳性。RNA/蛋白支持率、BUSCO、家族完整性、资源耗时为辅助指标。比较原始公开注释、统一基线、原始预训练模型、训练后模型，并做去掉各类证据/训练数据的消融。收益需在留出类群与独立证据上成立，不能只报告训练集BUSCO增加。

## QS016：后续开发记录与最小试验

用户授权本轮调研/记录，不自动启动全量reads下载、整门重组装或GPU训练。

建议先做12–20个系统分支分散的物种的小规模试验；数量只是预算起点，依实际高可信标签/类群覆盖调整。先盘点元数据和小文件，优先已有高质量FASTA＋匹配GFF/蛋白/RNA，避免先下载全部reads。随后对已有RNA与缺RNA情形分别选可用后端，验证格式、证据保留和质量，不预设统一最优软件。

| 开发模块 | 输入→输出 | 验收要求 |
|---|---|---|
| 公共资产登记/更新 | taxid/物种/项目→版本化资产清单 | 区分not_found/unknown/not_checked/present，不把检索失败视为无数据；去重同一INSDC数据 |
| 注释适配器QS015 | assembly＋证据＋类群→原生配置/候选/整合集 | 保存原版注释，查FASTA/GFF匹配，未验证类群显式阻止或标试验 |
| 核心家族与缺失诊断 | 蛋白/模型/基因组→家族、拷贝、占有率与位点证据 | 不把异构体/hap当重复基因或新物种；缺失允许unknown；审计旁系同源 |
| 训练集制作与划分 | 高可信模型＋证据→训练/验证/测试与弱标签表 | 标签来源可追踪，按类群留出，过滤相邻窗口与同物种泄漏 |
| 训练/评分与评估 | 固定基线、模型和划分→比较报告 | 不以BUSCO单指标判优；保留失败/无收益结果和重复运行配置 |
